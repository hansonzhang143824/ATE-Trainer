执行强度边界

日常 Offline Coding

  • 沿用原有工作流：解析意图 → 确认路径 → 生成方法 → 脚本检查 → 用户触发编译。
  • 按改动影响范围运行必要门禁，不默认重跑全量迁移验收。
VS

迁移 / 架构 / 生成器变更验收

  • 当前流程必须重新生成 SCH、COMPONENT、meta 和 manifest，并与 baseline 比较。
  • 指定目标项验证 meta → generated/source → VS active code 三层一致，并执行实际 VS 编译。
