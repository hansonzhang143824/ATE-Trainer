③ 主线流程（步骤化）

  1. 找 Pin（I） → 找通路（J，在 SCH_Connect-Map 里找）
  2. 分流判断（N）：是否含【差分 Pin 组 或 大电流】？
    是 → 走 S FPVI/QVM 通路 → W 判断通路是否存在？ 不存在→转 K 非稀缺；存在→D 组合 Pin 找最短
    否 → 走 K 非稀缺源表通路
  3. 最短通路（C）：所有通路放一起找每个 PIN 到源表最短
    单 PIN=PIN到源表 ｜ 组合 PIN=源表两端到两 PIN，含功能继电器
    （回流：K / D→T / U 的结果都回到 C 重新汇总）
  4. 冲突检查（T）：最短通路是否有冲突？
    • 是 → X 分时复用？ 是→L 列分时继电器→回 C；否→E 第二短无冲突？ 是→R 列第二短→回 C；否→P 放弃差分只保电流？ 是→O→U→回 C；否→F 报错
    • 否 → 回 C 继续汇总
  5. 全局冲突（B）：包含功能继电器后是否有冲突？否→A 列举继电器+找名→Q；是→M 非组合继电器第二短 → G 无冲突？ 是→A→Q；否→F 报错
  6. 分时复用（Q）：是→H 分多组闭合→V；否→V
  7. 终点（V）：调取 cbite.SetOn 用法，完成闭合操作

④ 关键要点

铁律：每个新 TM 必须重走本流程，禁止直接复制黄金案例的继电器结构（黄金案例只作同构参照）。
优先级（2026-08-30 用户权威）：差分/大电流 → 优先 FPVI/QVM（稀缺源表）；单 PIN/普通 → 非稀缺源表（FOVI/FXVI/ACM）。冲突降级链 = 分时复用 → 第二短通路 → 放弃差分只保电流 → 报错（本电路可满足则不裁决，缺失才阻塞）。
易错点：分时场景必须每组一次独立 SetOn——SetOn 是全量设置（先清后设、只闭列出），把两组宏合并进一次 SetOn 会造成两路并联。

⑤ 执行案例：TM1205（TRX_BST_UV_GD）

流程步执行结论
① 找 PinVBAT/BST1/BST2/SW1/SW2/nQON；差分对 = BST1−SW1、BST2−SW26 Pin，2 差分对
② 找通路BST1/2 只有 FPVIe Low(K41/K41+K43)，无 High；SW1/2 有 High(K46/K46+K49)+Low(K47/K47+K50)差分须 High→SW + Low→BST
③ 分流 NB SST1−SW1、BST2−SW2 均差分→是；VBAT/nQON 单 PIN→否差分走 FPVI/QVM；单 Pin 走非稀缺
④ 最短路1={K46,K41}；路2={K46,K49,K41,K43}；VBAT=FXVI(K8 NC)；nQON=K65_PU组合 Pin 并集最短，含功能继电器
⑤ 冲突 X路1/路2 都占 FPVI0 同一差分通道 → 冲突可分时（先路1后路2，DMUX 57→58）
⑥ 全局 B分时后继电器无额外冲突无冲突 → 列举继电器
⑦ 分时 Q有 → 分两组两组各独立 SetOn
⑧ 终点 V按 CBITe.h 全量语义分组独立 SetOn路2 必须重新 SetOn
