核心原则

一条规则 = 一个 ID = 一个正文位置；agent、脚本、记忆、报告只引用，不复制正文。
机台手册/API 是 L0 只读事实；只有被工程师确认并能约束生成行为的内容，才进入 L1 规则层。
经验、案例、库函数候选先进入 L2/reference/draft；不能直接污染 active rule。
