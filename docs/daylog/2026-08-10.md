## 规则修正 | Ramp 测试 Hys 单位规则 (R-HYS)

### 时间/事件
2026-08-10 | **规则新增 / 人工反馈**

- **适用范围**: 含 ramp 的 rise/fall/hys 三参数测试 (Toggle/AWG 两段式)
- **内容**: **如果 hys 是电压量 → 按 mV 为单位 log; 如果 hys 是电流量 → 按 mA 为单位 log**。
- **原因**: Rise/Fall 是触发点 ramp 电压/电流 (rampv_capv→V, rampi_capv→A), Hys = Rise − Fall 是差值 (数值小), spec 预期用小单位 mV/mA, 不是源表原始 V/A。
- **代码 diff**: `hys[site] = rise_result[site] - fall_result[site];` → `hys[site] = (rise_result[site] - fall_result[site]) * 1e3;  // V -> mV (R-HYS)`

- **来源**: 工程师口述 (2026-08-10)
- **初步分类**: **global rule** — 可泛化到所有含 Hys 参数的 ramp 测试项目。建议 rules-agent 提炼登记规则库 (R-HYS); 同步 check-agent 加 E026 + measure-agent 模式3 Toggle + units.md Hys 节 + skill Toggle 段。

### 时间/事件
2026-08-10 | **工具教训 / 批量生成复盘**
