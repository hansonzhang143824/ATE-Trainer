无缝接入机制

  • git diff 检测变更：新资料 / 改规则进库，靠 diff 而非传话。
  • 完整性审计脚本 gen_knowledge_audit.py：ID 连续 / 无重复、active 有强制层、反向引用（agent / 脚本引用的 ID 能查到）、来源清单对照（手册「已提炼 / 未提炼」）。⏳ 待建 执行顺序第 5 步
  • codegen 开始读 param_type_index：生成代码前查 references/param_type_index + functions-registry。
