③ Agent 分组总览（agents/ 目录共 19 个文件）
Agent 类型 触发 职责 / 产出
一、代码生成 Pipeline（主 Skill 编排，固定解析链 + CBIT-Definition）
dft-parse-agent Agent B 模式（仅 DFT） Step1 每次进入 DFT → TestItemMeta JSON（仅 DFT，源表映射按 SCH-Connect-Map 补齐）
cbit-agent Agent 编排 Step2 每次进入 有定义+dll距今>1天→仅 check / ≤1天跳过 / 无→完整四阶段（P1→P2→P3→P4）
cbit-path-namer Agent Step2 P3 通路继电器 #define 命名（命名优先级含人工判断，不脚本化）
relay-agent Agent Step4 循环内 环节② 统一单元：先通路 → 后角色 → 统一 cbite.SetOn() 封装 + pin-map 副产物（SCH-Connect-Map）
measure-agent Agent Step4 循环内 MI/MV/Toggle/Trim/AMUX-NTC 测量代码
check-agent Agent Step5 收尾 代码检查报告 PASS/FAIL/WARN（E 组错误码）
power-on / power-off-agent 脚本 规格文档 Step4 循环内 已脚本化 → gen_power_sequence.py（19 规则 --audit-rules 自检）
