四层收窄流程图

任一层的候选被淘汰即不进入下一层；每层先锁小范围，再在小范围内择优，全程不做"全网表枚举再筛"。

入 需求 DSL
  • fv:pin,<V> 静态电压　·　hc:<A>,pin 大电流　·　diff:pinA-pinB[,vrng] 真差分　·　fi:pinA-pinB,<A> 电流型 Pin2Pin　·　meas:pin / pw:pin,<V>
  • DSL 前加 ! 前缀 = DFT 点名特殊精度
① 能力白名单 REQ_RULES
  • 先锁源表类型，再列通路（不枚举全网表再筛）
  • 只遍历 PATH_COSTS[pin] 收录的行
  • hc≥200mA / fv>40V / fi≥200mA → FPVIe
  • 真差分（两点都非地）→ FPVIe / ACM200
  • 单端对地 → 排除 FPVIe
② 精度门 — "门"不是"筛" accuracy gate
DFT 点名精度（DSL ! 前缀）→ 收窄 {FPVIe, ACM200}
未点名精度→ ACM200/FOVIe/FXVIe/FXVIe_PLUS/FPVIe 全部通过，决策落 ③
  • 精度 = 满足性（satisfiability），不是择优性；能力硬约束是另一层，与精度门无关
③ 最短 / 第二短 drive_paths · lru 缓存
  • 白名单内按需闭合继电器数（并集）升序
  • 第 1 位 = 最短通路 · 第 2 位 = 冲突兜底（第二短）
  • Pin2Pin 特殊规则：可用 FPVIe 单通道浮动跨两点 → 算最短，优先于拆两个独立源表单端（TM641 方案B）
  • 实测排名：BST → ACM200 ch5 (K48+K76=2) < FPVIe ch0 (K46+K48+K76=3)
④ 跨需求重叠检测 avoid_relay_conflicts · 预计算+增量
  • 只扫已选中需求：预计算继电器集，仅被换路那条增量重算（不扫全部组合）
pin集相交[继电器共用] ✓ 良性共用，可并行（TM641 K61 先例）
pin集不相交→ 自动换第二短避让
避让成功[继电器避让] ✓ 不阻塞
第二短也撞[继电器冲突·残留] ⚠ 需串行，不阻塞
缺失无法满足✗ 阻塞裁决 超量程 hc>10A / fv>100V · Pin2Pin 两端无任何源
  • 冲突降级原则（用户拍板）：只要本电路可满足的都不需人工裁决；FPVIe 满 → 自动 ACM200 / 拆两独立源表单端 [自动降级/拆源表] ✓
出 规划输出
  • 源表 + 通道 + 需闭合继电器清单 + FPVIe 预算 + 冲突标注（共用/避让/残留/降级）
→ relay-agent 直接消费 Step1/2 通路继电器
  • 有规划输出（源表+通道+继电器）→ 不再手工全量穷举（relay-agent Step13 规划门优先）
  • 穷举法仅在无规划输出（人工兜底）时使用
