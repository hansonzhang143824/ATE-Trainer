芯片架构角度：BST与SW的“自举”设计
从芯片内部架构看，BST 和 SW 引脚是专为驱动高侧（High-Side）N沟道功率MOSFET或GaN FET而设计的。

核心问题：要让高侧开关完全导通，其栅极电压需比源极（即SW节点）电压高5V~10V。当高侧开关导通时，SW点电压接近输入电压（如12V、24V），此时芯片内部逻辑电压（如5V）无法提供足够高的栅极驱动电压。

解决方案（自举）：BST 和 SW 引脚间连接一个自举电容（Bootstrap Capacitor）。其工作原理利用了电容两端电压不能突变的特性：

充电阶段：当低侧开关导通时，SW引脚被拉低到接近0V。芯片内部二极管导通，用内部电源（如VCC）为自举电容充电，使其电压达到约5V。
抬升阶段：当高侧开关需要导通时，低侧开关关闭，SW引脚电压开始上升。由于电容两端电压不能突变，BST引脚的电压会被“自举”抬升到 V_SW + 5V。这个高于输入电压的电压，正是驱动高侧开关完全导通的关键。
简单来说，BST与SW形成了一个“浮动电源”，为高侧开关提供了必要的驱动电压。

🔌 应用角度：引脚连接与电压关系
在实际应用中，BST和SW引脚的连接和电压关系有明确的规范。

引脚连接：在BST和SW引脚之间，必须连接一个高质量、低ESR的陶瓷电容。容值通常为 0.01µF 到 0.1µF。

电压关系：芯片关注的并非BST或SW对地（GND）的绝对电压，而是两者之间的电压差 V(BST) - V(SW)。

正常工作：这个电压差应保持在一个稳定值（如5V），由内部稳压器或充电管理电路维持。

绝对最大值：芯片数据手册会规定BST-SW间的最大允许电压，例如不超过5.5V。

欠压阈值：为确保高侧开关能完全导通，BST-SW电压差必须高于一个最低阈值（如2.3V）。

🛡️ 功能角度：BST_UV——自举欠压保护
BST_UV 是 Bootstrap Undervoltage Lockout（自举欠压锁定） 的缩写，是一项关键的保护功能。

监控对象：持续监控 BST 和 SW 引脚之间的电压差 V(BST) - V(SW)。

触发条件：当BST-SW电压差低于芯片设定的阈值电压（V_BST_UV）且持续时间超过设定的抗干扰时间（t_BST_UV_DG）时，触发保护。不同芯片阈值不同，如ROHM BD9E151NUX为2.5V，TI DRV8329-Q1约5V。

保护动作：触发后，芯片会立即执行保护：

关闭驱动：将所有高侧和低侧驱动输出强制拉低，关闭所有外部功率开关管。
报告故障：通过 nFAULT 等故障指示引脚输出低电平，通知系统控制器。
故障锁存：故障状态通常被锁存，直到通过外部信号（如复位nSLEEP引脚）才能清除。
🧪 测试角度：如何验证BST_UV功能
验证BST_UV功能的核心是模拟欠压故障，并检查芯片响应是否符合预期。
从ATE（自动测试设备，Automatic Test Equipment）的工程视角来看，验证BST_UV功能的核心就是精确控制并扫描（Ramp）BST与SW之间的电压差（ΔV = V_BST - V_SW），以捕获保护触发点。

在ATE机上，无法像实验室那样依靠电感“自举”动态建立电压，而是通过Force（强制）电压来直接模拟这个差分电压。下面是ATE测试的具体工程化实现方案：

1. ATE测试硬件配置（如何建立压差）
在ATE系统中，BST和SW都是高压引脚（可能高达24V/40V），通常由ATE的 HV-PMU（高压源测量单元） 或 DPS（器件电源） 通道驱动。
BST和SW脚的处理：
方案一，采用浮动源绑定BST和SW，例如FPVI，对于BST和SW的绝对电压没有要求,但是一般来说寄存器配置会把下管打开，SW与PGND短路，等于0V。此时ΔV = V_FPVI

方案二：BST和SW采用不同源控制
SW引脚处理：将低侧驱动强制开启（或强制PWM为低电平），并由ATE的HV源将SW引脚强制钳位在GND（0V）。这样，SW的电压就被固定住了（V_SW = 0V）。
BST引脚处理：由另一路独立的HV-PMU通道对BST引脚施加一个可编程的扫描电压（V_BST）。
此时，ΔV = V_BST - 0 = V_BST。因此，扫描BST引脚电压，就等于直接扫描BST-SW的电压差。

2. 测试执行流程（Ramp过程）
ATE测试程序按以下序列执行，这个序列通常写在测试机台的Pattern（向量）或Level（电平）设定中：

Step 1：初始化与强制模式
上电后，配置寄存器实现：将芯片设置为开环测试模式（或强制PWM低电平），确保高侧开关（HS）强制关闭，低侧开关（LS）强制导通（或体二极管续流状态），使SW节点处于低阻抗的GND状态，程序不卡控。

Step 2：施加初始高压
ATE的HV源向BST引脚施加一个远高于欠压阈值的电压（例如，若阈值是2.5V，则施加5V），此时ΔV足够高，芯片认为自举电容充电充足，nFAULT引脚处于高电平（无故障），这里等效是：DTEST0或者DMUX，都是从功能角度给的代称，实际中是 对应每个项目的PIN不同。

Step 3：向下扫描电压（Ramp Down）
ATE机台以极小的步进（例如 1mV ~ 10mV）和特定的斜率（Slew Rate，如 1V/ms）向下步进（Ramp Down） BST引脚上的输出电压。

3. 捕获与测量（Capture & Measure）
在电压步进下降的过程中，ATE同时进行以下同步测量：

电压阈值捕获（V_BST_UV）：
ATE的数字比较器（Comparator）实时监测 nFAULT 引脚的电平。当监测到 nFAULT 从逻辑“1”翻转为逻辑“0”（即触发欠压保护）的瞬间，ATE会锁存当前时刻施加在BST引脚上的电压值。该读取值即为实测的欠压保护触发阈值。


4. 向上扫描电压，保护功能验证（输出钳制检查）
触发故障后，ATE不会立即结束，而是会继续执行两步校验：

迟滞（Hysteresis）验证：ATE继续向下扫描一段距离（低于阈值很多），然后改为向上扫描（Ramp Up） BST电压。记录nFAULT重新恢复为高电平（故障清除）时的电压值。这个值与向下扫描时的触发值之差，即为保护功能的迟滞电压（防止电压在阈值边缘抖动时频繁触发）。


总结ATE测试的注意事项
开尔文（Kelvin）连接：由于BST-SW电压差精度要求高，ATE探针卡上必须使用开尔文连接（Force+Sense），以消除测试路径上的线缆压降，确保读数准确。

扫描速率（Slew Rate）控制：Ramp斜率不能太快（否则TMU测不准），也不能太慢（影响测试成本，即Test Time）。通常ATE工程师会基于数据手册的t_BST_UV_DG时间设定一个折中的扫描速率（如保证每个步进稳定 10µs）。

温度补偿：BST_UV阈值具有温度漂移特性，ATE测试通常会在常温（25°C）和高温（如125°C）下分别执行此Ramp测试，以覆盖全温度范围的规格。

这种通过 “固定SW，线性扫描BST” 的ATE方法，是量产测试中衡量该保护功能良率最标准、最快速的手段。如果芯片支持读取内部寄存器，ATE还会顺便回读故障状态位（如UV_FLAG）进行数字逻辑校验。
