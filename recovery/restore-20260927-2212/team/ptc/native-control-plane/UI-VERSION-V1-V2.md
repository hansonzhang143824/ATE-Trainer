# Agent Trainer 工作台 UI 版本

## V1（当前改版前基线）

V1 是本次视觉改版前的全屏浮层布局。它保留当前的 DSH 宿主结构、全屏工作区、公开 slot 注册方式和所有运行控制行为。V1 的颜色、字号和间距作为回退基线保留。

## V2（视觉试用版）

V2 保留 V1 的全屏布局，不采用居中窄画布，也不改变 PTC 控制面、原生会话或业务数据。改动集中在视觉表达：提高文字对比度和字号、改善边界与间距，并使用统一状态色：

- 完成：绿色
- 执行中：橘黄色
- 报警、失败和中断：红色
- 未开展、尚无运行：中性灰蓝

V2 默认启用，顶部会显示 `V2 · 合成训练·演示数据`。

## 切换方式

顶部的 `V1 样式` / `V2 样式`按钮可以即时切换。选择会保存到浏览器 `localStorage` 的 `trainer-workbench-ui-version-v1-v2`键；没有保存偏好时默认使用 V2。切换只改变视觉主题，不改变运行、会话绑定、版本和发布功能。
