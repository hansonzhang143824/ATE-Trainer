## 1. 列11 完整 5 类分类定义

新增列 `## 列11: 通路分类 (P2P / 上拉 / 下拉 / 稳压)`，每类带**分类标签**。

**终端集（分类 BFS 的终止判据，只穿越继电器 K\*，不穿越 R/C）：**

| 终端类型 | 识别 | 方向 |
|---|---|---|
| DUT PIN | PORT/NET_LABEL 形如 `<base>_F_S?` / `<base>_S_S?` | 通路起点 |
| 上拉电源-固定 | POWER_PORT `S34_J+5V`（唯一固定轨，无 12V） | 上拉（固定 5V） |
| 上拉电源-源表 | 源表端口 `S\d+_(FOVIe|ACM200|FPVIe|ACM|HVIe|HPVIe|QVMe|FXVIe)_` | 上拉（range 内任意电压） |
| 地 | POWER_PORT `AGND/DGND/JGND` **或** `AGND_F_S1` / `AGND_S_S1` | 下拉 |

### 1.1 P2P 短路（两方向，各标类别）
- **P2P-到地**：`PIN ↔ AGND`（继电器端点一侧 = DUT PIN，另一侧 = 地脚 AGND_F/AGND_S），ON 数 ≤ 2。
- **P2P-互短**：`PIN ↔ PIN`（继电器端点两侧 = 两个不同 DUT PIN base），ON 数 ≤ 2。
- 数据源：按继电器**端点 net** 解析（不依赖现有 relay_class，因 G6K 名带 P2P 会被误归 Share）。

### 1.2 上拉通路（标签 `上拉`，分两子类）
- 结构：`PIN + 电阻 + 继电器 + 上拉电源`。
- **判定：PIN → 电阻（不看值）→ 继电器 → 上拉电源**。电阻端点的两 net 一个含 DUT PIN、另一个经继电器（K\*）到达「上拉电源」终端。
- **两子类（语义不同，必须分开标）**：
  - `上拉-固定5V`：上拉电源 = POWER_PORT `S34_J+5V`（只能 5V）。
  - `上拉-源表`：上拉电源 = 源表端口。**源表可输出 range（电压量程）内任意电压，具备上拉到 range 内所有电压的能力，不限 5V**。测时电压由源表 FV 设定（range 内）。
- **本板 7 个**：`R_SCL_PU` `R_SDA_PU` `R_nQON_PU`（→固定 5V，经 K34/K63/直连）+ `R_PA0_PU` `R_PA1_PU` `R_PA6_PU` `R_PA7_PU`（→源表 FOVIe FH7/SH7，经 K103/K108/K113/K122 → `PU_PS_S1` → K128）。

### 1.3 下拉通路（标签 `下拉`）
- 结构：`PIN + 电阻 + 继电器 + 地`。
- 地 = AGND/DGND/JGND 机台地 **或** AGND_F_S1/AGND_S_S1 芯片地脚 **或** 模拟源表端口（源表 FV=0V 等效接地，本板未出现此形态）。
- **判定：PIN → 电阻（不看值）→ 继电器 → 地**。
- **本板 3 个**：`R_PA1_PD` `R_PA4_PD` `R_PC4_PD`（→AGND_F_S1，经 K149/K150/K148，值 15K）。

### 1.4 Kelvin 电阻（**不**进列11，是上拉/下拉的排除判据）
- 结构：电阻两端 net **直接**（不穿越继电器）分别含 Force 端口与 Sense 端口（同一 base）。
- 本板 54 个系列电阻：`R_PA0_S1` `R_PD2_S1` `R_PD3_S1` `R_PD5_S1` …（含 `R_*_KLV_S1`）。
- **判据必须用「直接」F/S，不能经继电器追**：因为 Force 线经 K102 等继电器连到 Sense 线，若经继电器追会把上拉电阻误判成 Kelvin。

### 1.5 稳压通路（标签 `稳压`）
- 结构：`PIN + 电容 + 继电器`。
- 判定：PIN → 电容(**值 ≥ 100nF**) → （继电器）。**按值判，不看名字**。

## 2. 通路有效性三规则（剪枝源表通路）

- **Rule A（硬）— 禁止穿越固定电压节点**：
  - 固定电压节点 = **地**（机台地 AGND/DGND/JGND + 芯片地脚 AGND_F/AGND_S，0V）∪ **固定电源轨**（S34_J+5V，5V；通用含 12V）。
  - **核心判据**：源表→PIN 通路不得穿越任何固定电压节点。固定节点的电压硬件钉死、源表改不了；通路一旦经过，源表（程控源，输出可调）会与固定电压**相互对拉**，**无法独立控制通路电压** → 非法。
  - 固定节点作为**终点**合法，作为**中间节点**非法。
- **Rule B（硬）— 禁止穿越其他 PIN**：源表→PIN 通路不得穿越其他 PIN。BFS 到达含 DUT PIN 的 net 后记录 proof 并**停止展开**（terminal-stop）。合并短接节点（同 net 多 PIN）天然正确。
- **软规则**：穿越其他源表 → 只加 `⚠经过源表` 警告，不剪（源表是可编程的，不是固定电压，属"另一条源表通路"而非"固定节点对拉"）。

> 已机器验证的事实：机台地裸 net（AGND/DGND/JGND）无继电器连接（只连 0Ω 电阻 + POWER_PORT），trace 图里是死胡同；真正被穿越的固定 0V 节点是芯片地脚 `AGND_F_S1`（17 个 P2P 继电器 + 源表 FL 返回线接它，已确认短接机台地）。固定 5V 轨 `S34_J+5V` 是另一类固定电压节点（接 EEPROM + 3 个上拉电阻）。

## 3. 器件值解析规范（值权威 CSV ComponentValue，仅稳压用）

CSV 的 `ComponentValue` 列经 adapter 嵌入合成 EDIF 为 `(Property Value (String "VAL"))`。提取 `位号 -> 值字符串` 后规范化：

| 值字符串 | 规范化 | 单位 |
|---|---|---|
| `1K` / `1k ohm` / `100mohm` / `0 Ohm` | 数值 × 倍率 | 欧姆 |
| `10nF` / `100nF` / `220nF` / `4.7uF` / `2.2uF` | 数值 × 倍率 | 法拉 |

- 电阻：`K`=×1e3，`M`=×1e6，`m`=×1e-3，`R`/无=×1。忽略 `ohm`。（上拉/下拉**不用电阻值**，解析仅备用。）
- 电容：`uF`=×1e-6，`nF`=×1e-9，`pF`=×1e-12，`mF`=×1e-3，`F`=×1。
- 阈值比较：稳压 `farad >= 1e-7`（100nF）。

值读取封装成单一函数 `load_component_values(netlist_path)`，返回 `{位号: value_string}`；后续用户把值并入 csv 后，该函数切换到读 csv 值列，**分类逻辑不动**。

## 4. 实现方案（精确到 file）

### 4.1 legacy `sch_parse.py`（主引擎，生成 SCH-Connect-Map）

**改 1 — 值读取**（导入区后新增）
```python
def load_component_values(netlist_path):
    """EDIF 位号->值 (Property Value)。仅稳压分类用；后续并入 csv 后改读 csv 值列。"""
    txt = open(netlist_path, encoding='utf-8', errors='ignore').read()
    vals = {}
    for m in re.finditer(r'\(Instance\s+(\S+)', txt):
        name = m.group(1)
        seg = txt[m.start():m.start()+2000]
        vm = re.search(r'\(Property\s+(?:\(rename\s+\S+\s+\"[^\"]*\"\)\s+)?Value\s+\(String\s+\"([^\"]*)\"\s*\)', seg)
        if vm and vm.group(1).strip():
            vals[name] = vm.group(1).strip()
    return vals
```

**改 2 — 终端集 + 固定电压节点集 + 被动元件扩展**（`net_class` 附近 + 继电器分类附近）
- `FIXED_VOLTAGE_NETS = 所有 POWER_PORT net`（地 AGND/DGND/JGND/AGND_F_S1 + 电源轨 S34_J+5V）∪ `{AGND_S_S1}`。**地 + 固定电源轨都算固定电压节点**（0V / 5V 硬件钉死）。
- `SUPPLY_RAIL_NETS = POWER_PORT 且非地`（本板 = {S34_J+5V}，供列11 上拉-固定5V 分类用）
- `SOURCE_METER_PORTS = PORT 名匹配 r'^S\d+_(FOVIe|ACM200|FPVIe|ACM|HVIe|HPVIe|QVMe|FXVIe)_'`
- `PASSIVE_CELLS = {'Res2': 'R', 'Cap': 'C'}`（把 2 脚被动元件也纳入通路边，带值）
- 列11 分类用终端集：上拉-固定（`SUPPLY_RAIL_NETS`）/ 上拉-源表（`SOURCE_METER_PORTS`）/ 地（`FIXED_VOLTAGE_NETS` 中地子集）/ DUT PIN（F/S 端口）。

**改 4 — 列11 生成**（任务六输出区，附注前）
- 新增 `## 列11`，输出 5 段：

## 6. 已闭环决策（本次对话确认，无遗留阻塞）

1. **100nF 边界**：`≥ 100nF`（含 100nF）。
2. **上拉到源表语义**：源表 = 可编程电压源，输出 range（电压量程）内任意电压；上拉到源表 = 具备上拉到 range 内所有电压的能力，不限 5V。列11 分「上拉-固定5V」与「上拉-源表」两类，不写成「源表FV=5V」。
3. **Rule A 固定节点**：固定电压节点 = **地（0V）∪ 固定电源轨（5V/12V）**，共同点电压硬件钉死、源表改不了。核心判据 = 源表通路经过固定电压节点会与固定电压**对拉**，无法独立控制通路电压 → 排除。
