## 枚举总览

### VIMode — 工作模式
- `FV` — 恒压模式
- `FI` — 恒流模式

### ACM200_VRNG — 电压量程
- `ACM200_40V` — 40V量程
- `ACM200_20V` — 20V量程
- `ACM200_10V` — 10V量程
- `ACM200_3p6V` — 3.6V量程

### ACM200_IRNG — 电流量程
- `ACM200_200MA` — 200mA量程
- `ACM200_100MA` — 100mA量程
- `ACM200_10MA` — 10mA量程
- `ACM200_1MA` — 1mA量程
- `ACM200_100UA` — 100uA量程
- `ACM200_10UA` — 10uA量程
- `ACM200_1UA` — 1uA量程

### ACM200_OUT_RELAY — 输出继电器状态
- `ACM200_RELAY_HOLD` — 保持上一个状态
- `ACM200_RELAY_ON` — 打开输出继电器（FORCE+SENSE同时打开）
- `ACM200_RELAY_OFF` — 关闭输出继电器
- `ACM200_RELAY_SENSE_ON` — 独立测量模式（仅打开SENSE，关闭FORCE），此时ACM200处于独立电压表模式

### FLOATMEASMODE — 测量模式
- `MEAS_NORMAL` — 普通测量模式，调用函数后完成测量
- `MEAS_AWG` — AWG测量模式，只做设置，运行AWG时启动

### MeasRet — 测量读回数据类型
- `MVRET` — 回读电压测量数据（单位V）
- `MIRET` — 回读电流测量数据（单位A）

### TRIG_MODE — 触发模式
- `TRIG_FALLING` — 下降沿触发
- `TRIG_RISING` — 上升沿触发

### ACM200_CONTACTMODE — 接触检测模式
- `ACM200_HIGH_SIDE` — 检测高端电路的连接
- `ACM200_LOW_SIDE` — 检测低端电路的连接

### AWG运行模式
- `AWG_SINGLE` — 运行一次AWG波形
- `AWG_LOOP` — 循环运行AWG波形（使用AwgStop()停止）

### CAL_RESULT — 校准结果
- `CAL_PASS` — 校准PASS
- `CAL_FAIL` — 校准FAIL
- `STS_NO_RESULT_RECORD` — 读取校准结果异常

### CAL_METER — 校准表类型
- `STS_KEITHLEY2000` — Keithley 2000
- `STS_AGILENT34401` — Agilent 34401
- `STS_AGILENT3458A` — Agilent 3458A
- `STS_NO_METER_RECORD` — 读取校准表信息异常

## 6.3.1 ACM200() — 构造函数

**Signature:**
```cpp
ACM200(char* channelList, char* chName = NULL);
```

**Parameters:**
- `channelList` — ACM200绑定通道字符串。形如 `"S5_0,S5_1"`，其中 `S5` 表示槽位号5（S即Slot），`0、1` 表示板内序号（0-23）。一块ACM200板卡最多24个通道，共四个bank，每个bank最多6个通道。
- `chName` — 通道的自定义名称。默认NULL，系统命名为 `ACM200_xx`。

**Remarks:**
- 定义一路ACM200通道，并指定其包含的实际通道信息（"槽位号+板内序号"）。

**Example:**
```cpp
// 4块ACM200（Slot5、Slot11、Slot22、Slot28），四工位并行
ACM200 ACM200_0("S5_0,S11_0,S22_0,S28_0");
ACM200 ACM200_1("S5_1,S11_1,S22_1,S28_1");
// ... 最多到 ACM200_11

// 工位绑定
STSSetMultiSiteBind(MD_ACM200, SITE_1, "S5_0-11");
STSSetMultiSiteBind(MD_ACM200, SITE_2, "S11_0-11");
STSSetMultiSiteBind(MD_ACM200, SITE_3, "S22_0-11");
STSSetMultiSiteBind(MD_ACM200, SITE_4, "S28_0-11");
```

## 6.3.2 Set() — 设置电压/电流

**Signature:**
```cpp
int Set(
    VIMode viMode,
    double setValue,
    ACM200_VRNG vRange,
    ACM200_IRNG iRange,
    ACM200_OUT_RELAY relayStatus = ACM200_RELAY_HOLD,
    double risingTime = 0.1
);
```

**Parameters:**
- `viMode` — `FV`(恒压) 或 `FI`(恒流)
- `setValue` — 设定值。FV模式下单位V，范围-40~40；FI模式下单位A，范围-0.2~0.2
- `vRange` — 电压量程，见枚举 `ACM200_VRNG`
- `iRange` — 电流量程，见枚举 `ACM200_IRNG`
- `relayStatus` — 输出继电器动作，默认 `ACM200_RELAY_HOLD`
- `risingTime` — 变化时间，单位mS，分辨率0.01mS，默认0.1mS
  - <=0.05mS → Fast模式（0.05mS）
  - <=0.1mS → Normal模式（0.1mS）
  - >0.1mS → 自动启动Capload功能，最大值65mS

**Return:** 0 = 成功

**Remarks:**
- 设置ACM200的状态，包括工作模式、恒压或恒流值、电压量程或电流量程、输出继电器状态及Capload时间。

**Example:**
```cpp
// 5V输出，默认risingTime
ACM200_0.Set(FV, 5, ACM200_10V, ACM200_100MA, ACM200_RELAY_ON);

// 带Capload，risingTime=3mS
ACM200_0.Set(FV, 0, ACM200_10V, ACM200_100MA, ACM200_RELAY_ON);
delay_ms(1);
ACM200_0.Set(FV, 5, ACM200_10V, ACM200_100MA, ACM200_RELAY_ON, 3);
```

## 6.3.3 SetSyn() — 同步设置（多工位不同值）

**Signature:**
```cpp
int SetSyn(
    VIMode viMode,
    const double* setValue,
    UINT siteSize,
    ACM200_VRNG vRange,
    ACM200_IRNG iRange,
    ACM200_OUT_RELAY relayStatus = ACM200_RELAY_HOLD,
    double risingTime = 0.1
);
```

**Parameters:**
- `viMode` — `FV` 或 `FI`
- `setValue` — double数组，每个工位的设定值。FV单位V，范围-40~40；FI单位A，范围-0.2~0.2
- `siteSize` — 执行同步操作的工位数（如4表示SITE1~SITE4）
  - setValue数组长度必须大于siteSize
  - siteSize小于有效工位数时，未设定工位保持原状态
  - siteSize大于有效工位数时，按实际有效工位数处理
- `vRange` — 电压量程（所有工位同一量程）
- `iRange` — 电流量程（所有工位同一量程）
- `relayStatus` — 输出继电器状态
- `risingTime` — 变化时间（同上）

**Return:** 0 = 成功; -1 = 不支持Group功能

**Remarks:**
- 对不同的工位设定不同的电压值或电流值，且该操作对不同工位完全同步。

**Example:**
```cpp
// SITE1输出3V，SITE2输出5V，同步输出
double setValue[2] = {3, 5};
int siteSize = 2;
ACM200_0.SetSyn(FV, setValue, siteSize, ACM200_10V, ACM200_100MA, ACM200_RELAY_ON);

// 带Capload
ACM200_0.Set(FV, 0, ACM200_10V, ACM200_100MA, ACM200_RELAY_ON);
delay_ms(1);
ACM200_0.SetSyn(FV, setValue, siteSize, ACM200_10V, ACM200_100MA, ACM200_RELAY_ON, 3);
```

## 6.3.4 SetClamp() — 设置箝位

**Signature:**
```cpp
int SetClamp(
    double percent_PFS,
    double percent_NFS
);
```

**Parameters:**
- `percent_PFS` — 正箝位值，占正箝位满量程的百分比，单位%，范围 2~105
- `percent_NFS` — 负箝位值，占负箝位满量程的百分比，单位%，范围 2~105

**Return:**
- 3 = 正负箝位皆发生变化
- 2 = 负箝位变化
- 1 = 正箝位变化
- 0 = 正负箝位皆未发生变化
- -9 = 通道无效

**Remarks:**
- 设置ACM200的正负箝位值。
- **重要：SetClamp与模式相关，切换FV/FI模式时会清除箝位设置，箝位值自动还原成105%。未切换FV/FI时箝位设置保持不变。**

**Example:**
```cpp
// FI模式箝位到(50,20)
ACM200_1.Set(FI, 0, ACM200_10V, ACM200_10MA, ACM200_RELAY_ON);
ACM200_1.SetClamp(50, 20); // 正箝位50%, 负箝位20%

// 切换到FV模式后箝位自动恢复105%，需要重新设置
ACM200_1.Set(FV, 0, ACM200_10V, ACM200_100MA, ACM200_RELAY_ON);
ACM200_1.SetClamp(25, 25);
ACM200_1.Set(FV, 1, ACM200_10V, ACM200_100MA, ACM200_RELAY_ON);

// 同一模式下（FV不变），箝位保持
ACM200_1.SetClamp(50, 25);
ACM200_1.Set(FV, 1, ACM200_10V, ACM200_100MA, ACM200_RELAY_ON);
delay_ms(1);
ACM200_1.Set(FV, 25, ACM200_40V, ACM200_100MA, ACM200_RELAY_ON);
ACM200_1.MeasureVI(100, 20);
ACM200_1.Set(FV, 0, ACM200_40V, ACM200_100MA, ACM200_RELAY_ON);
ACM200_1.SetClamp(100, 100);
```

## 6.3.5 MeasureVI() — 设置测量

**Signature:**
```cpp
int MeasureVI(
    UINT sampleTimes,
    double samplePeriod,
    FLOATMEASMODE measMode = MEAS_NORMAL,
    UINT T1 = 0,
    UINT T2 = 0,
    UINT T3 = 0,
    UINT T4 = 0
);
```

**Parameters:**
- `sampleTimes` — AD采样次数，范围 1~4096（<1时取1，>4096时取4096）
- `samplePeriod` — 采样间隔，单位uS，范围 1~30000，分辨率1uS（<1时取1，>30000时取30000）
- `measMode` — `MEAS_NORMAL`(普通测量) 或 `MEAS_AWG`(AWG测量模式)。默认 `MEAS_NORMAL`
- `T1, T2, T3, T4` — AWG测量模式下四次测量启动时刻，单位uS，分辨率10uS，总和范围 0~600000
  - 这四个参数为相对时间：T2相对T1，T3相对T2，T4相对T3
  - 默认都为0（启动一次，启动时刻为0）

**Return:** 1 = AWG模式下测量设置成功; 0 = DC模式下设置成功; -4 = Group通道不能进行AWG测量

**Remarks:**
- 设置ACM200的测量次数、测量间隔、测量模式以及AWG测量模式下的四次测量启动时刻。

**Example:**
```cpp
// 普通模式，采样20次，间隔10uS
ACM200_0.MeasureVI(20, 10);
```

## 6.3.6 GetMeasResult() — 获取测量结果

**Signature:**
```cpp
double GetMeasResult(
    UINT siteCount,
    MeasRet retType = MVRET,
    int sampleNumber = AVERAGE_RESULT,
    BYTE triggerNum = 0
);
```

**Parameters:**
- `siteCount` — 工位选择，0=Site1, 1=Site2, ...
- `retType` — `MVRET`(电压) 或 `MIRET`(电流)，默认 `MVRET`
- `sampleNumber` — 返回数据类型：
  - `AVERAGE_RESULT` — 平均值（默认）
  - `MAX_RESULT` — 最大值
  - `MIN_RESULT` — 最小值
  - `TRIG_RESULT` — 触发值（AWG同步测量时跳变触发的位置，即第几个采样点发生跳变，最多支持两次触发）
  - 非负值N — 第N+1个采样点的值，0 <= N <= sam-1
- `triggerNum` — 仅当sampleNumber=`TRIG_RESULT`时有效，最多支持两次触发：
  - 0 = 回读vTrig/iTrig第一次触发位置（默认）
  - 1 = 回读vTrig/iTrig第二次触发位置
  - 2 = 回读vTrig2/iTrig2第一次触发位置
  - 3 = 回读vTrig2/iTrig2第二次触发位置

**Return:**
- 选择TRIG_RESULT时：正常返回触发点位置；异常返回 -1/-2/-3/-12/-20/-22
- 未选择TRIG_RESULT时：正常返回测量结果（V或A）；异常返回 2.00e+15/4.00e+15/9.00e+15

**Remarks:**
- 获取MeasureVI()的测量结果。
- MVRET回读结果为电压值(V)，MIRET回读结果为电流值(A)。
- ACM200每次测量时电压和电流同时测量，只需选择读回MVRET或MIRET。

**Example:**
```cpp
// 返回电流平均值
ACM200_0.MeasureVI(20, 10);
for (i = 0; i < SITENUM; i++) {
    adresult[i] = ACM200_0.GetMeasResult(i, MIRET);
}

// 返回第15个采样点的电压值
ACM200_0.MeasureVI(20, 10);
for (i = 0; i < SITENUM; i++) {
    adresult[i] = ACM200_0.GetMeasResult(i, MVRET, 14);
}

// AWG同步测量，返回触发位置
ACM200_0.SetMeasVTrig(2, TRIG_FALLING);
ACM200_1.MeasureVI(50, 20, MEAS_AWG);
ACM200_0.MeasureVI(50, 20, MEAS_AWG);
STSEnableAWG(&ACM200_1);
STSEnableMeas(&ACM200_1, &ACM200_0);
STSAWGRun();
for (i = 0; i < SITENUM; i++) {
    Trig_Point0[i] = ACM200_0.GetMeasResult(0, MVRET, TRIG_RESULT, 0);
    Trig_Point1[i] = ACM200_0.GetMeasResult(0, MVRET, TRIG_RESULT, 1);
}
```

## 6.3.7 BlockRead() — 数据块读取

**Signature:**
```cpp
int BlockRead(
    UINT siteCount,
    UINT start,
    UINT size,
    double* buffer,
    MeasRet retType = MVRET
);
```

**Parameters:**
- `siteCount` — 工位选择，0=Site1, 1=Site2, ...
- `start` — 数据块起始地址，非负整数，范围 0 ~ (采样次数-1)
- `size` — 数据块大小，正整数，范围 1 ~ (采样次数-start)
- `buffer` — 存放结果的数组（建议定义为全局变量），长度需不小于size
- `retType` — `MVRET`(电压) 或 `MIRET`(电流)，默认 `MVRET`

**Return:** 0 = 成功; -1 = 不支持Group; -2 = 工位无效; -10 = 测量未启动

**Remarks:**
- 读取一个数据块的测量结果，起始地址和大小由用户定义。

**Example:**
```cpp
double result[SITENUM][200] = {0.0};
ACM200_0.MeasureVI(200, 10);
for (i = 0; i < SITENUM; i++) {
    ACM200_0.BlockRead(i, 0, 200, result[i], MVRET);
}
```

## 6.3.8 Pulse() — 脉冲输出

**Signature:**
```cpp
int Pulse(
    double pulseValue,
    UINT pulseTime = 300,
    int measStartTime = 0,
    UINT sampleTimes = 10,
    double sampleInterval = 30
);
```

**Parameters:**
- `pulseValue` — 脉冲幅值。FV模式单位V，范围-40~40；FI模式单位A，范围-0.2~0.2
- `pulseTime` — 脉冲时间，单位uS，分辨率10uS，范围 300~40000，默认300uS
- `measStartTime` — 启动测量时间，单位uS，范围 -60000~60000，默认0
- `sampleTimes` — 采样次数，范围 1~4096，默认10
- `sampleInterval` — 采样间隔，单位uS，范围 1~30000，分辨率1uS，默认30uS

**Return:** 0 = 成功; -1 = 不支持Group功能

**Remarks:**
- 输出幅度、脉宽可调的电压或电流脉冲。
- **重要：Pulse之前需先调用Set设置量程等信息。Pulse脉冲的起始值和终止值均为Set语句设置值。**

**Example:**
```cpp
ACM200_0.Set(FV, 0, ACM200_10V, ACM200_10MA, ACM200_RELAY_ON);
// 输出8V、1mS脉冲，脉冲前500uS开始测量，采样200次，间隔10uS
ACM200_0.Pulse(8, 1000, -500, 200, 10);
```

## 6.3.9 AwgLoader() — 导入AWG波形数据

**Signature:**
```cpp
int AwgLoader(
    char* awgName,
    VIMode viMode,
    ACM200_VRNG vRange,
    ACM200_IRNG iRange,
    double* awgData,
    UINT awgSize
);
```

**Parameters:**
- `awgName` — AWG波形名称（不区分大小写）
- `viMode` — `FV` 或 `FI`
- `vRange` — 电压量程（仅用于波形数据换算，不涉及档位切换）
- `iRange` — 电流量程（仅用于波形数据换算，不涉及档位切换）
- `awgData` — double型指针，存储AWG波形数据
- `awgSize` — 波形数据大小，范围 1~4096

**Return:**
- 1 = 加载成功，但某物理通道缺失该AWG数据，需重新加载
- 2 = 加载成功，该逻辑通道中不存在此AWG数据
- 0 = 加载成功，所有物理通道都存在该AWG数据
- -1 = 不支持Group功能

**Remarks:**
- 导入AWG波形数据。档位信息仅用于波形数据换算，不涉及档位切换。
- 同一路ACM200通道可导入多个AWG波形，但名称必须不同。相同名称只写入第一次调用的波形。
- 一次性写入4096个点约需5mS，写入时间与点数成正比。
- **同一个测试程序中，同一路通道每次导入的AWG波形总长度必须<=4096，超出不写入RAM。**
- 建议总长度<4096，此时同一个AWG数据不会被重复导入，仅第一次执行AwgLoader占用测试时间。

**Example:**
```cpp
// 斜波：16.5V -> 21.5V，步距0.1V
int sam = 50;
double awg_pattern[100] = {0.0};
STSAWGCreateRampData(&awg_pattern[0], sam, 1, 16.5, 21.5);
ACM200_0.AwgLoader("Vst", FV, ACM200_40V, ACM200_100MA, awg_pattern, sam);

// 正弦波：100Hz, Vpp=4V, DC=10V
int sam = 1000;
double awg_pattern[2000] = {0.0};
STSAWGCreateSineData(&awg_pattern[0], sam, 1, 4, 10, 0);
ACM200_0.AwgLoader("Sine", FV, ACM200_40V, ACM200_100MA, awg_pattern, sam);
```

## 6.3.10 AwgSelect() — 选择AWG波形（用于同步运行）

**Signature:**
```cpp
int AwgSelect(
    char* awgName,
    UINT startAddr,
    UINT stopAddr,
    int loopBackAddr,
    double awgInterval = 10.0
);
```

**Parameters:**
- `awgName` — AWG波形名称，需与AwgLoader中的名称一致
- `startAddr` — 波形起始点，范围 0 ~ sam-1
- `stopAddr` — 波形结束点，范围 0 ~ sam-1
- `loopBackAddr` — 波形回转点（AWG执行结束后停止的位置）
  - <0 → 保持在运行结束的位置
  - 0~sam-1 → 保持在设定点位置
- `awgInterval` — AWG数据间隔时间，单位uS，分辨率1uS，范围 10~60000，默认10uS

## 6.3.14 SetMeasVTrig() — 电压测量触发设置

**Signature (两个重载):**
```cpp
// 单次触发
int SetMeasVTrig(
    double vTrig,
    TRIG_MODE trigMode = TRIG_FALLING,
    double hysteresisValue = 0.0
);

// 二次触发
int SetMeasVTrig(
    double vTrig,
    TRIG_MODE trigMode,
    double hysteresisValue,
    double vTrig2,
    TRIG_MODE trigMode2,
    double hysteresisValue2
);
```

**Parameters:**
- `vTrig` — 第一次触发电压，单位V（值与Set函数的电压档位相关），最多触发两次
- `trigMode` — `TRIG_FALLING`(下降沿) 或 `TRIG_RISING`(上升沿)，默认 `TRIG_FALLING`
- `hysteresisValue` — 第一次触发滞回值，单位V，仅可设置为非负值，默认0
- `vTrig2` — 第二次触发电压，单位V，最多触发两次
- `trigMode2` — 第二次触发模式
- `hysteresisValue2` — 第二次触发滞回值，单位V，仅可设置为非负值

**触发判定逻辑:**
- 上升沿(TRIG_RISING)：测量结果先小于(vTrig-hysteresisValue)，之后又大于vTrig → 判定为触发
- 下降沿(TRIG_FALLING)：测量结果先大于(vTrig+hysteresisValue)，之后又小于vTrig → 判定为触发

**Return:** 0 = 成功; -1 = 不支持Group功能

**Remarks:**
- 电压测量触发设置。
- **SetMeasVTrig与MeasureVI运行时，对应的电压电流档位状态必须一致。二者之间不允许插入改变电压电流量程档位的函数。**

**Example:**
```cpp
// 第一次下降沿9V触发，第二次上升沿8.6V触发
ACM200_1.Set(FI, 0, ACM200_10V, ACM200_10MA, ACM200_RELAY_ON);
ACM200_1.SetMeasVTrig(9, TRIG_FALLING, 0, 8.6, TRIG_RISING, 0);
ACM200_0.MeasureVI(sam, interval, MEAS_AWG);
ACM200_1.MeasureVI(sam, interval, MEAS_AWG);
STSEnableAWG(&ACM200_0);
STSEnableMeas(&ACM200_0, &ACM200_1);
STSAWGRun();
```

## 6.3.31 VI源编程范例

### 6.3.31.1 多波形拼接
使用STSAWGCreateSineData/TriangleData/SquareData/RampData创建不同波形放入同一个awg_pattern数组的不同偏移位置，一次AwgLoader加载后通过AwgSelect选择运行范围。

### 6.3.31.2 正弦波测试纹波抑制比(PSRR)
ACM200_0输出正弦波，ACM200_1在FI模式测量，逐点回读计算峰峰值和PSRR = -20*log10((Vpp+1e-12)/0.66)。

### 6.3.31.3 同一路生成AWG且作为触发源
ACM200_0输出AWG斜波，对自身电流进行触发（SetMeasITrig），通过TRIG_RESULT获取触发点位置，再回读该位置电压值。

### 6.3.31.4 一路源生成AWG另一路作为触发源
ACM200_0输出AWG斜波，ACM200_1做电压触发（SetMeasVTrig），从ACM200_1获取触发点位置，回读ACM200_0在触发点的电压值。

### 6.3.31.5 多路并联输出电流
GangRelay并联后GangSet设置电流，GangMeasure测量，GangGetMeasResult回读电压和电流，最后GangSet(0)和GangReset。

### 6.3.31.6 多点触发
使用SetMeasVTrig设置两次触发（vTrig上升沿+滞回, vTrig2下降沿+滞回），通过GetMeasResult的triggerNum=1和triggerNum=3分别获取第二次和第四次触发位置。
