# ACM200 源表参考

## 概述
ACM200 — 精密源测量单元，非浮空源（Low端默认接AGND）。

## Set 函数签名
```cpp
<ResourceName>.Set(mode, value, vRange, iRange, RELAY);
```

## 模式
| 模式 | 含义 | 使用场景 |
|------|------|----------|
| `FV` | Force Voltage | vset 指令 |
| `FI` | Force Current | iset 指令（非浮动源） |

## RELAY 控制
| 值 | 含义 |
|----|------|
| `ACM200_RELAY_ON` | 源表输出导通 |
| `ACM200_RELAY_OFF` | 源表输出断开 |

## 量程表

### 电压量程
| 设定值范围 | 选用量程 |
|-----------|---------|
| V ≤ 1.8V | `ACM200_3p6V` |
| V ≤ 5V | `ACM200_10V` |
| V ≤ 20V | `ACM200_40V` |

### 电流量程
| 设定值范围 | 选用量程 |
|-----------|---------|
| I ≤ 500nA | `ACM200_1UA` |
| I ≤ 5μA | `ACM200_10UA` |
| I ≤ 50μA | `ACM200_100UA` |
| I ≤ 500μA | `ACM200_1MA` |
| I ≤ 5mA | `ACM200_10MA` |
| I ≤ 50mA | `ACM200_100MA` |
| I ≤ 100mA | `ACM200_200MA` |

## 量程选择规则
**量程 ≥ 2 × 设定值**，选最接近的一档。

## MeasureVI 函数
```cpp
<ResourceName>.MeasureVI(sampleCount, discardCount);
```
- sampleCount: 采样次数（常用 50）
- discardCount: 异常值剔除数（常用 5）

## GetMeasResult 函数
```cpp
<ResourceName>.GetMeasResult(site, MIRET);  // 电流测量
<ResourceName>.GetMeasResult(site, MVRET);  // 电压测量
```

## 所在槽位
S5, S6, S11, S12, S21, S22, S27, S28 — 每槽 24 通道 (FH/SH 0~23)
