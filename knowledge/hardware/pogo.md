# POGO 点位 — 机台通道物理引出

## 概念

机台安装板卡后，**所有板卡通道引出到 POGO 点位**。POGO 是测试机台与 DUT（芯片）之间的物理接触点。

```
板卡槽位 → 源表通道 → POGO 点 → [继电器] → [电阻/电容] → 芯片 Pin
```

## 命名规则

POGO 点名称 = 源表通道名称：
```
S28_ACM200_FH2    → Slot 28, ACM200, Force High, 通道 2
S30_FOVIe_SH3     → Slot 30, FOVIe, Sense High, 通道 3
S24_P15           → Slot 24, DCM, Pin 15
```

### 关键规则: FL/SL 分组共享

```
FH/SH: 每通道独立 → 通道之间互不影响
FL/SL: 分组共享   → 同组内所有通道共用同一个 Low 端回路!
```

**闭环判定影响:** 同 FL 组的多个通道，Low 端是共用的。只要该组的 FL 接好 AGND_F，组内任意通道就能形成闭环。

```
示例: ACM200 FL(0-11) 接 AGND_F
  → FH0~FH11 任意一个的 High 到达 Pin → 闭环 ✓
  → FH12~FH23 的 High 即使到达 Pin → 开环 ✗ (FL(12-23)需要用另一个FL组)
```

## 闭环判定

### 基本条件

**High 端到达 + Low 端到达 → 闭环**

```
High 端: POGO点 → [继电器(需闭合)] → [电阻] → Pin → 到达!
Low 端:  POGO点 → [继电器(需闭合)] → [电阻] → AGND/Pin/短路线 → 到达!
```

### FL/SL 分组影响

```
ACM200 FL(0-11) 接 AGND_F:
  FH0~FH11  任意通道 High 到达 Pin → 闭环 ✓  (共用 FL(0-11))
  FH12~FH23 任意通道 High 到达 Pin → 开环 ✗  (FL(12-23) 未接!)

需要用 FH12 → 必须确保 FL(12-23) 也接了 AGND_F
```

### 特殊情况

| 源表 | 闭环条件 |
|------|----------|
| **DCM** | 仅 High 到达 → 闭环 (Low 已接 DGND) |
| **QTMUe** | 仅 High 到达 → 闭环 (Low 已接 DGND) |
| **QVMe** | SH + SL 都到达 → 闭环 (两端浮动) |
| **FPVIe** | FH + FL 都到达 → 闭环 (两端浮动, 独立) |
| **电源轨** | 仅输出端到达 → 闭环 (Low 已接 JGND) |

## GND 短接关系

```
AGND_F_Sx (芯片 Force 地) → AGND (机台模拟地) → DGND (数字地) → JGND (机壳地)
```

4 个地在机台上互通。Low 端接到任意一个地 = 到达回路。

---

## 多 Site 对应

每个 Site 有独立的 POGO 和信号路径：

| Site | 后缀 | 继电器例 |
|------|------|---------|
| Site 1 | `_S1` | K31_BUS_PMID_S1 |
| Site 2 | `_S2` | K31_BUS_PMID_S2 |

板卡通道通过继电器矩阵分配到不同 Site。程序中引用时去掉 `_S1`/`_S2` 后缀。
