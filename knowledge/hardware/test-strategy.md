## 一、电流范围 → 源表选型

| 电流范围 | 可用源表 | 说明 |
|---------|---------|------|
| **≥200mA** | **仅 FPVIe** | ACM/ACM200/FOVIe/FXVIe/FXVIe_PLUS 都无法提供 ≥200mA DC 电流 |
| <200mA | ACM200 / FOVIe / FPVIe 等 | 非大电流场景，按需分配 |

```
判断逻辑:
  IF 电流 ≥ 200mA → FPVIe（唯一选择）
  IF 电流 < 200mA → 按 SCH-Connect-Map 和闭环规则选择源表
```

## 二、小差分电压生成（≤20mV）

### 问题场景

在两个 Pin 之间产生 ≤20mV 的差分电压。

### 三种方案优先级

| 优先级 | 方案 | 精度 | 误差估算 |
|:---:|------|------|---------|
| ⭐⭐⭐ **最优** | FPVIe 在小电阻(<1Ω)上 force 电流，运放采集差分电压 | **0.1mV 级** | 电流精度 × 小电阻 |
| ⭐⭐ 中等 | FPVIe 直接输出 20mV | ~2.0mV (10%) | 最小量程 1V × 0.2% |
| ⭐ 最低 | 两个独立源 V1/V2 → 算 V1−V2 | >2.5mV | 0.5% 精度叠加，V1/V2 往往 >1V |

### 最优方案实现条件

```
FPVIe ──→ 小电阻(<1Ω) ──→ 电阻两端电压 ──┬── 继电器 ──→ PinA Force 端
                                         └── 继电器 ──→ PinB Force 端
FPVIe 职责: 测量流过电阻的电流 + 电阻两端电压差
运放职责:  在 PinA Sense / PinB Sense 端测量差分电压
```

### ⚡ 强制前提：浮动源 4-wire Kelvin Sense 必须到达电压测量点

**通用原则（E010）：** 浮动源产生差分电压时（force电流过电阻 / 直接FV输出跨Pin），**SH/SL 必须到达电压测量点**。测量点通常是 RS 两端（测电流用）或 DUT 引脚（测DUT电压用）。从 SH/SL 出发，经过的所有 Sense 通路继电器必须闭合。

> 2-wire 模式（短接 FH/SH、FL/SL）精度退化，仅在不要求精度的场景可用。

**以 NU6810 HIB 为例（RS_S1 作为采样电阻）：**

```
SH0 → [Sense通路继电器] → FH_PC (RS高端)
SL0 → [Sense通路继电器] → FL_PC (RS低端)
```

具体到该板卡：K43(通电:3-4,6-5) + K46(通电:3-4,6-5) + K41_F(OPEN) + K41_S(OPEN)。
**不同 HIB 设计的 Sense 通路继电器名称不同，但原则不变：从 SH/SL 到测量点的路径上所有继电器必须闭合。**

### 关键约束

- 电阻 <1Ω
- 电阻两端电压通过继电器引入目标 Pin 的 **Force 端**
- 差分电压用**运放**在目标 Pin 的 **Sense 端**测量
- FPVIe 只负责电流源+电流电压测量，不直接参与差分电压的测量

## 三、资源冲突优先级

### 只出现电压差（如 BST↔SW）

| 优先级 | 方案 |
|:---:|------|
| 1st | FPVIe 通过 Kelvin 连接到 Pin 两端。若 Pin 非 Kelvin，FPVIe 在 Pin 处通过继电器短接 Force 和 Sense |
| 2nd | FPVIe 被占用 → 用两个独立源给 Pin 上电，保持电压差 |

### 电压差 + 电流同时出现

| 场景 | FPVIe 指派 |
|------|-----------|
| 电流 ≥200mA | **FPVIe 给电流**，电压差用两个独立源 |
| 电流 <200mA | FPVIe 可给电压差，但**优选给电流** |

```
决策树:
  电流 ≥ 200mA ?
    ├─ 是 → FPVIe = 电流源（强制）
    │        电压差 = 两个独立源
    └─ 否 → FPVIe 可用 ?
              ├─ 未被占用 → 优先给电流，其次给电压差
              └─ 已被占用 → 电流/电压差用其他源
```

## 四、运放使用规范

### 三个必要条件（缺一不可）

| 条件 | 检查 | 违反后果 |
|------|------|---------|
| ① 供电电压 | V+/V- 双电源（或 V+/GND 单电源）均不能浮空 | 运放不工作 |
| ② 差分输入 | IN+/IN- 必须有信号接入，不能浮空 | 输出不确定 |
| ③ 输出测量 | 输出端必须有测量源（源表/ADC）来读取 | 信号丢失 |

### 双电源 vs 单电源

| 接法 | V+ | V- | 适用 |
|------|----|----|------|
| 双电源 | +15V (S34_+15V) | -15V (S34_-15V) | 信号可正可负 |
| 单电源 | +15V (S34_+15V) | GND | 信号仅正 |

> 无论哪种接法，两个电源输入都必须有通路，不能浮空。

## 五、与非 Kelvin Pin 的配合

当 FPVIe 连接到非 Kelvin Pin（Pin 只有一根线，Force/Sense 不分）：

```
FPVIe FH/SH ──→ 继电器 ──→ [短接 FH+SH] ──→ 非 Kelvin Pin
```

**在到达非 Kelvin Pin 之前，通过继电器将 FPVIe 的 Force 和 Sense 短接。**

这符合 Non-Kelvin 结构的定义：Force 和 Sense 在到达芯片 PAD 之前（在 Pin 的 copper 处）短接。
