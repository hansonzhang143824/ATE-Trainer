# 差分电压对 ATE 通用处理规范（diff-pair-spec）— 以 BST−SW 自举为例

- 生成：2026-09-02 用户提供芯片架构/测试角度知识 + TM1205(BST_UV)/RDSON 实际处理沉淀
- 定位：`relay-design-flow.md` ③分流「差分 Pin 组」分支的**执行细则**；新 TM 遇差分电压对（Hybrid：BST−SW、PinA−PinB）必须先查本规范
- 铁律：差分对的被测对象是**压差 ΔV = V(PinA) − V(PinB)**，不是对地绝对电压；选型、扫描、观测都以 ΔV 为中心

## 一、芯片架构背景（BST−SW 自举）

BST 与 SW 是驱动**高侧（HS）N 沟道 MOSFET/GaN** 的一对引脚。高侧开关完全导通需：
```
VGS = V(HS栅极) − V(源极SW) ≥ 5V ~ 10V
```
BST−SW 间连接**自举电容**（0.01~0.1µF，低 ESR），利用"电容两端电压不能突变"把 BST 抬升到 V_SW + 5V。

- **充电**：低侧开关导通时 SW≈0V，内部二极管用 VCC 给自举电容充到约 5V
- **抬升**：高侧开关需导通时低侧关断、SW 上升，BST 被自举到 V_SW+5V
- **芯片关注**：`V(BST) − V(SW)` 压差，非对地绝对电压
- **绝对最大值**：通常 ≤5.5V；**欠压阈值**：低于（如 2.3V）触发保护

## 二、BST_UV（自举欠压锁定）功能

- 监控：持续监控 ΔV = V(BST) − V(SW)
- 触发：ΔV < **V_BST_UV** 且持续 > **t_BST_UV_DG**（去抖）→ 触发保护
- 动作：①关闭所有高/低侧驱动（拉低）；②nFAULT 等故障脚拉低；③锁存（需复位清除）
- 观测：nFAULT 是**功能代称**，实际观测脚 = DTEST0 / DMUX / 各项目不同 PIN，须按项目解析

## 三、ATE 通用处理

### 1. 施加方案（二选一）

| 方案 | 做法 | ΔV | 前提 |
|---|---|---|---|
| **方案一（浮动源）** | FPVI 跨 PinA/PinB **两端** | ΔV = V_FPVI（正域） | 另一端被内部钳位到 GND（如开下管→SW≈0V）或两端绝对电压自由（Hybrid 适用） |
| **方案二（单端）** | 钳位一端（强制低侧开/强制 PWM 低→SW=0V），扫描另一端 | ΔV = V_扫描端 | 需芯片可强制某端到 0V；单端精确 |

> 选型优先级（relay-design-flow ③）：差分/大电流 → **优先 FPVI/QVM**（浮动差分源）；否则非稀缺源表。差分对用浮动源天然满足"跨两端、只保压差"。

### 2. 扫描方向（捕获触发 + 迟滞）

```
向下扫描(Ramp Down) → 捕获【触发阈值】(欠压/过压保护动作点)
     ↑ 步进 1~10mV, 斜率 1V/ms (兼顾 TMU 精度与测试时间)
向上扫描(Ramp Up)   → 捕获【恢复阈值】(迟滞/故障清除点)
     Rise(上扫恢复) − Fall(下扫触发) = 迟滞电压 Hys
```

- **同步测量**：数字比较器实时监测观测脚（nFAULT/DTEST0/DMUX），翻转瞬间锁存当前施加电压 = 实测阈值
- **迟滞校验**：触发后继续扫一段→回扫上扫，记录恢复电压，差值即迟滞（防阈值边缘抖动误触发）

### 3. 结果换算

- 方案一（浮动源）：捕获值 = 浮动源输出电压 = ΔV（**直接**，无需减偏置）
- 方案二（单端）：捕获值 = 扫描端电压 = ΔV（因另一端钳 0V）
- 观测脚与 ramp 反向约定（TM641/TM643 同）：
  - **升扫（ΔV 增大）** → TRIG_FALLING 捕 **rise**（释放阈值）
  - **降扫（ΔV 减小）** → TRIG_RISING 捕 **fall**（触发阈值）

### 4. 工程注意事项

- **Kelvin（开尔文）四线**：ΔV 精度高，Force+Sense 分离，消除线缆压降
- **扫描斜率**：不能太快（TMU 测不准），不能太慢（增加测试成本）；按 t_BST_UV_DG 折中（如每步稳定 10µs）
- **温度补偿**：阈值温度漂移，量产常温(25°C)+高温(如125°C) 分别执行
- **可选回读**：若支持内部寄存器，回读故障状态位（如 UV_FLAG）作数字逻辑校验

## 四、与"测上管 RON"的区分（易错）

| | BST_UV（欠压锁定） | 上管 RON（导通电阻） |
|---|---|---|
| 目的 | 让 HS 关断/触发欠压保护 | 让 HS **完全导通** |
| VGS(BST−SW) | 扫描到**低于阈值**触发 | 保持 **≥5V** 恒定（充分导通） |
| SW | 钳位/扫描 | 随 PMID 抬升（导通后 SW→PMID） |
| 施加 | 浮动源扫描 ΔV | BST−SW 恒 5V + PMID 台阶 + FPVI 大电流 |

## 五、TM1205 实例（BST1−SW1 / BST2−SW2）

- 差分对 = BST1−SW1、BST2−SW2（两组，独立参数）
- 选源：FPVI0 浮动差分（H→SW侧 + L→BST侧）；两路共用 FPVI0 通道 → **分时复用**（relay-design-flow ⑦）
- 极性：V(BST) > V(SW)，FPVI 输出 = V(SW)−V(BST) ∈ [0,−4]V（负域）；若开下管使 SW≈0V 则 ΔV=V_FPVI 正域——**按下管是否被寄存器钳位决定正/负域**（待 TM1205 具体寄存器确认）
- 扫描：0→−4V（上扫 释放/rise） + −4→0V（下扫 触发/fall），nQON 翻转观测，Hys=(rise−fall)×1e3 mV
