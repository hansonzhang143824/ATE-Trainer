# 模块 06：过压保护 OVP（Over Voltage Protection）

> 初稿（待用户校验）：领域知识整理。用于 OVP 类测试（如 VBAT_OVP、VBUS_OVP、输出过压）。
> ⏳ **待用户修改校验**。

## 1. 功能

**OVP**：检测电压（输入/输出/某引脚）超过设定上限 → 触发保护（关断/钳位），防止过压损坏。
与 UVLO（欠压）方向相反：**OVP 是电压过高、UVLO 是电压过低**。

## 2. 硬件结构（监控对象）

| OVP 类型 | 监控对象 | 触发动向 |
|---|---|---|
| **VBUS/VBAT OVP** | 输入电源电压 | 高于阈值 → 关断输入 |
| **VOUT OVP** | 输出端电压 | 高于阈值 → 关断输出/钳位 |
| **VBUS loop** | 输入环路电压 | 环路指示器翻转 |

多数带**迟滞**（Hys）与**去抖**（防噪声误触发）。内部通过**分压 + 比较器**实现（如用 VREF 比较）。

## 3. ATE 测试方法（通用）

- **施加**：扫描监控电压（单端对地：VBUS/VBAT；差分：如 VBAT loop）
- **扫描**：电压从低→高（上扫）捕**触发阈值**；再从高→低（下扫）捕**恢复阈值**
- **迟滞**：`Hys = 触发阈值 − 恢复阈值`（升扫触发 - 降扫恢复）
- **注意方向**：OVP 与 UVLO 的"触发/恢复"对应方向相反——**OVP 上升沿触发**，UVLO 下降沿触发
- **观测**：芯片输出/状态翻转（nFAULT、DTEST0/DMUX——功能代称，按项目解析）

## 4. 派生知识（可推导的测试要求）

| 想问/要测 | 推导 |
|---|---|
| **测 OVP 触发** | 电压从低到高扫 | 捕上扫触发阈值（比对 UVLO 是下扫触发） |
| **OVP 迟滞** | 高→低扫捕恢复阈值 | Hys = 触发 − 恢复 |
| **扫描方向** | OVP **上扫捕触发**；UVLO **下扫捕触发** | 方向相反，别搞反 |
| **VREF 相关** | 若用 VREF 比较 → 需稳定 VREF（有些测试先测 VREF） | 黄金案例 TM425 有 VREF 测量 |

## 5. 易错点

- ❌ 把 OVP（上扫触发）当 UVLO（下扫触发）→ 扫描方向反
- ❌ 忽略 VREF 依赖（比较器基准）→ 若 VREF 未稳，触发点测偏
- ✅ OVP 触发后芯片关断，需恢复电压（下扫）才能复位——两方向都要测
