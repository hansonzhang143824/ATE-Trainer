# 模块 05：过流保护 OCP（Over Current Protection）

> 初稿（待用户校验）：领域知识整理。用于 OCP 类测试（如 BOOST HS OCP、电流限制）。
> ⏳ **待用户修改校验**。

## 1. 功能

**OCP**：检测输出/开关管电流超过设定阈值 → 触发保护（限流/关断/打嗝 hiccup），防止过载烧毁。
监测对象：流过功率开关管（HS/LS）或输出的电流。

## 2. 硬件结构（电流路径与检测点）

- **电流路径**：输入 → HS/LS 开关管 → 电感 → 输出（电流流过功率级）
- **检测方式**（芯片内部）：
  - **采样电阻**：串联一个已知电阻，测其压降（V=I×R）
  - **电流镜/Current Sense（模块 07）**：镜像开关管电流，内部比较
  - **Rdson 检测**：利用开关管导通电阻 VDS=I×Rdson（无额外采样电阻，损耗小）
- **检测点**：开关管 Drain-Source 压差（如 PMID−SW）、采样电阻两端

## 3. ATE 测试方法（通用）

- **施加**：建立电流通路（开关管导通 + 负载），逐步增大电流（或通过引脚加载电流）
- **扫描**：电流从低→高，捕 OCP 触发点（芯片限流/关断动作）
- **观测**：芯片输出/状态翻转（限流时输出下降/关断；nFAULT、DTEST0/DMUX——功能代称，按项目解析）
- **电流方式**：大电流注入（≥200mA）用 FPVI（稀缺源表）；普通电流用非稀缺源表
- **工程**：Kelvin 四线（测 VDS 压差）、电流稳定性（自热影响）

## 4. 派生知识（可推导的测试要求）

| 想问/要测 | 推导 |
|---|---|
| **测 OCP 阈值** | 建立电流通路 + 逐步加流，捕芯片限流/关断点 |
| **为何用 FPVI 大电流** | OCP 电流常 ≥200mA → FPVI（大电流源，见 relay-design-flow ①） |
| **测开关管压差** | 用 Rdson 检测 → 测 VDS（PMID−SW）→ 配合电流算 RON |
| **工作状态** | 测 OCP 前需开关管导通（HS 需自举、LS 直驱——模块 03） |

## 5. 易错点

- ❌ 测 OCP 时管子没导通（尤其 HS 没建自举）→ 电流通路不存在 → 测不到
- ❌ 电流加太快/太大 → 自热影响 RON/阈值准确性
- ❌ 混淆 OCP（电流过高）与 UVLO/OVP（电压类）——方向与对象不同
