# 模块 07：电流检测 Current Sense

> 初稿（待用户校验）：领域知识整理。用于电流检测/测量类测试（如 IBUS current sense、电流阈值、镜像）。
> ⏳ **待用户修改校验**。

## 1. 功能

**Current Sense（电流检测）**：把流过的电流转换成电压信号（V=I×R 或电流镜像），供测量/监测/保护用。
核心是**测电流**——用电流检测电阻/镜像，得到与电流成比例的电压。

## 2. 硬件结构（检测结构与量程）

- **检测结构**（两种）：
  1. **检测电阻（Shunt/Rsns）**：串联已知电阻，V_sns = I × Rsns（精密、需 Kelvin）
  2. **电流镜（Current Mirror）**：镜像开关管电流按比例缩小，I_mirror = I × (1/N) → V=I_mirror×R（无额外功率损耗）
- **检测端**：金属节点、采样电阻两端（Force/Sense 分离 = Kelvin 四线）
- **输出**：检测电压送内部比较器/ADC（如 VCS、AMUX 观测）

## 3. ATE 测试方法（通用）

- **施加**：建立电流（开关管导通，注入已知电流 I）
- **测量**：读检测电压（V_sns = I×Rsns 或 V_mirror）→ 反推电流
- **增益/线性**：多档电流扫描 → 斜率 = 检测增益；偏移 = Vos（零电流偏移）
- **观测**：AMUX/VDM 等观测脚读检测电压（功能代称，按项目解析）
- **工程**：Kelvin 四线（精密电流测量）、量程匹配（电流 ≤ 源表量程的 1/2）

## 4. 派生知识（可推导的测试要求）

| 想问/要测 | 推导 |
|---|---|
| **测电流检测增益** | 多档已知电流 → 读检测电压斜率 = 增益 |
| **测电流检测偏移 Vos** | 零电流 → 读检测电压偏移量 |
| **精确测电流** | 用 Kelvin 四线 + 量程 ≥ 2× 电流 |
| **大电流检测** | 需 FPVI（大电流源）；小电流普通源表 |

## 5. 易错点

- ❌ 测电流时量程不够（电流 > 源表量程 2×）→ 饱和/测不准
- ❌ 忽略 Kelvin 四线 → 线缆压降混入检测电压
- ✅ Current Sense 特征：**给电流测试电压，且非 ramp**（用户 2026-10 权威点：SENSE 是电流阈值，若含 ramp 则不是 Current Sense）
