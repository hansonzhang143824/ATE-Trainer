# 模块 04：欠压锁定 UVLO（Under Voltage Lockout）

> 初稿（待用户校验）：领域知识整理。用于 UVLO 类测试（如 BST_UV、VBAT_UV、VCC_UV）。
> ⏳ **待用户修改校验**。

## 1. 功能

**UVLO**：当电源电压（或某引脚压差）低于设定阈值时，芯片**禁止/关闭**内部电路，防止欠压下误动作。是电源芯片最基础的保护之一。
BST_UV 是 UVLO 的子类——专门监控 **BST−SW 压差**（自举欠压，见模块 01）。

## 2. 硬件结构（监控对象）

| UVLO 类型 | 监控对象 | 典型阈值 |
|---|---|---|
| **VBAT/VIN UVLO** | 输入电源电压 | 如 2.7V~4.0V |
| **VCC/LDO UVLO** | 内部逻辑供电 | 如 2.5V |
| **BST_UV（自举）** | **V(BST)−V(SW) 压差** | 如 2.3V~5V |

多数带**迟滞（Hysteresis）**：上升沿开启阈值 > 下降沿关闭阈值，防抖动误触发。部分带**去抖（deglitch t_UV_DG）**。

## 3. ATE 测试方法（通用，diff-pair-spec 的"单端扫描"变形）

- **施加**：扫描监控电压（单端对地：如 VBAT、VCC；差分对：BST−SW）
- **扫描**：电压从高→低（下扫）捕**关闭/触发阈值**；再低→高（上扫）捕**开启/恢复阈值**
- **迟滞**：`Hys = 上扫恢复阈值 − 下扫触发阈值`（防抖动）
- **去抖**：需维持低于阈值超过 t_UV_DG 才触发 —— 扫描斜率不要太快（给去抖时间），否则测不准
- **观测**：芯片状态/输出翻转（如使能脚、nFAULT、DTEST0/DMUX——功能代称，按项目解析）
- **注意**：UVLO 关键是**区分"开启"与"关闭"两个阈值**（迟滞），不是单阈值

## 4. 派生知识（可推导的测试要求）

| 想问/要测 | 推导 |
|---|---|
| **BST_UV 触发点** | 扫描 BST−SW 从高到低，捕观测脚翻转 = 触发阈值 |
| **UVLO 迟滞** | 上扫捕恢复阈值，Hys = rise − fall |
| **为什么要扫两方向** | UVLO 有迟滞，单向扫只能测一个阈值 |
| **扫描斜率限制** | 去抖时间存在，斜率太快会漏触发/测不准 |

## 5. 易错点

- ❌ 只扫单向 → 测不到迟滞，只得到一半信息
- ❌ 扫描太快 → 去抖不相符，阈值测偏
- ❌ 把 UVLO（关断保护）与 OVP（电压过高保护）混淆——方向相反

## 6. 实例引用

- TM1205（BST_UV）：BST1−SW1/BST2−SW2 差分扫描，nQON 观测，双扫 + Hys
- TM641/TM643（BUBO BST_UV / VBAT Loop）：Toggle 双扫 + nQON 观测
- 历史 TM111（VBAT_UV）、TM113（VCC_UV）
