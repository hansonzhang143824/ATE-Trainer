# 差分电压对 要点总结（Diff Pair · 两端压差阈值 AWG）

> 源文件：`L4-Golden-code/TM1205_TRX_BST_UV_GD.cpp`（TM1205，112 行）｜索引登记：**Diff Pair**（差分电压对，BST−SW 自举为例）—— `rampv_capv` 浮动源跨两点 **负域双扫** + 观测脚翻转 + Hys=(rise−fall)×1e3；**两路共用同一浮动源 → 分时复用**。
> 关联：`L3-method/diff-pair-spec.md`（差分对 ATE 通用规范）、`L1-chip/01-bootstrap-hs-drive.md`、`L4-Golden-code/UVLO.cpp`（**单端**阈值 AWG，与之互补）。

## 1. 参数类型

- **差分电压对阈值 AWG**：被测对象是 **两个节点的压差 ΔV = V(PinA) − V(PinB)**，**不是对地绝对电压**。
- 与 `UVLO.cpp`（单端：一条 rail 对地）的**关键区别**：单端把一端当地、ramp 另一端；差分必须**一个浮动源同通道跨两点**，且**极性**由两端相对高低决定（本案例=浮动源输出负域）。
- 典型族：BST−SW（自举欠压）、任意 PinA−PinB（Hybrid 压差阈值）。

## 2. 角色抽象（精髓）

- **浮动源角色**：一个**稀缺浮动源的单通道**（H→两端之一、L→另一端）——它输出的是 **ΔV 本身**，捕获值 **直接等于压差，无需减偏置**（对照单端方案要扣对地偏置）。
- **极性角色**：先判哪端高。**高端接浮动源 High、低端接 Low** ⇒ 输出正域；**反接** ⇒ 输出负域（本案例 V(BST)>V(SW)，High→SW、Low→BST ⇒ 输出 ∈[0,−4]V）。
- **观测角色**：比较器/指示脚的**功能代称**（本案例=DTEST0 经 DMUX 引出到 nQON）。**Open-Drain 指示脚必须上拉**（PU 继电器）；观测只写 PIN，不写源表对象。
- **内部 MUX 角色**：`DMUX_SEL` 选**哪一对/哪一路**送入观测脚——**多对测试靠它逐路切换**，不是靠改继电器就能观测到另一路。
- **供电角色**：不参与 ramp 的 rail 固定供电（本案例=VBAT 静态），其 Cap 照 FR-001 正常闭合。
- 下一项目：把「两端」换成新项目的那一对（如 SW1↔VBUS、BST2−CFH2），**写法不变**；PIN 名零可迁移性。

## 3. 关键结构/特殊点（四类）

① **被测件本体结构**：差分对的两个端点各是谁（本案例 BST↔SW 自举对）。**极性决定浮动源输出的正/负域** —— 这是与所有单端案例最容易搞错的一点。

② **差分路径 → 浮动源单通道跨两点**：差分对**必须**用浮动源 H/L 分别接两端。**禁止**拆成两个独立单端源再软件相减（真差分语义 > 单端各自最短之和，见 `path-principles.md` ②'）。

③ **配对结构 = 被测压差两端的直连电容**：自举电容（Cap_SWx_BSTx）就并在这两端的压差上 → 它是**差分 ramp 源的 Cap** ⇒ **按 FR-001 反向规则不闭合**（闭了会拖慢 ramp、把阈值测歪）。这条最反直觉：**看起来该"稳压"的电容，因为是 ramp 源两端反而不闭**。

④ **测试方法本质 = 压差阈值**：`rampv_capv(浮动源, …, 观测源, …)` 做**两段双扫**；升扫（ΔV 增大）`TRIG_FALLING` 捕 **rise**、降扫 `TRIG_RISING` 捕 **fall**；**负域结果必须 `fabs()` 还原成压差**（正域案例直接取值、不取绝对值）；`Hys=(rise−fall)×1e3` mV。

**多路分时复用（本案例第二路）**：两对差分**共用同一个浮动源通道** ⇒ 按路切换。**路2 必须重新 `cbite.SetOn(...)`**（SetOn 是全量设置：先清后设、只闭列出）——**把两组宏合并进一次 SetOn 会让两路并联**（`relay-design-flow.md` §五 的易错点）。

## 4. 上电/下电时序

- 上电：`SetOn(浮动源 High→一端 宏, 浮动源 Low→另一端 宏, 供电 rail 的 Cap, 观测脚上拉)` → delay 3ms → **浮动源先置差分 0**（两端等电位）→ 供电 rail 上电 → delay → I2C。
- 下电：**浮动源差分回 0** → delay → 供电 rail→0 → delay → 统一 `RELAY_OFF`（含观测源）。
- 多路切换：**先切继电器（重新 SetOn）→ delay 3ms → 再改 DMUX_SEL**，顺序不能反。

## 5. 测量与判定

- `rampv_capv(浮动源, 浮动源量程, 大电流档, 观测源, 观测量程, 小电流档, start, stop, 200, 20, 1.65, TRIG_FALLING, rise[])` + 降扫 `TRIG_RISING, fall[]`；本案例负域 ⇒ `start=0, stop=−4`。
- `FOR_EACH_VALID_SITE` 内：`rise = fabs(rise_raw)`、`fall = fabs(fall_raw)`、`hys = (rise − fall) * 1e3`；参数 **每组 3 个** `<基名>_Rise/_Fall/_Hys`（多对 = 多组，如 `BST1_UV_*` + `BST2_UV_*`），LogData 逐个 SetTestResult。

## 6. 一句话适用场景

**任何"两端压差"阈值测试**（自举欠压 BST−SW、Hybrid 压差、PinA−PinB 阈值）：照本文件取「浮动源跨两点 + 极性判定 + 负域 fabs + 双扫 Hys」；**多对时**再加「分时复用 + 每路独立 SetOn + DMUX 逐路切换」。**继电器一律按角色从本项目权威源重新解析，绝不抄本文件的 Kxx。**
