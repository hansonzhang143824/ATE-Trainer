# RDS(on) 调试/排查方法论（debug）

> 四件套之一：出问题时按本篇排查。正常测量流程见 `L3-method/RDSON`；原理见 `L1-chip/RDSON`。
> 贯穿全篇的根本原则：**由外而内、由简入繁**。约 80% 问题在硬件连接和接触。

## 三类问题分类

| 类 | 现象 |
|---|---|
| 第一类：未进入测试模式 | 电流为 0、读数超量程、所有 DUT 或特定 Site 全部 Fail |
| 第二类：测试值有偏差 | 偏大/偏小、Site 间差异大、与仿真不匹配、固定漂移 |
| 第三类：测试不稳定 | 重复性差、初测复测差异大、测试顺序影响结果 |

## 标准排查顺序（7 步法，由外而内）

1. **DUT 导通状态**：确认功率管真被打开（万用表通断档蜂鸣，断点位置须避免大电流施加状态）
2. **电流路径**：确认测试电流沿设计路径流过功率管（大电流源继电器连接正确性）
3. **Kelvin 测量点**：电压测量点是否在正确的 Kelvin Sense 点（多引脚功率管 Sense 点选择）
4. **仪器状态**：PMU/DPS 是否在正确量程、未进入 Clamp
5. **测试时序**：导通建立/稳定/采样时间是否充足（尤其 VGS 正确施加在栅极）
6. **外部干扰**：温升、接触电阻、板级压降，或合理补偿
7. **系统比对**：ATE 与仿真在完全相同条件下比对（如 Metal/RDL 是否包含）

**经验法则**：约 80% 问题源于硬件连接和接触（步骤 1-3）；约 15% 源于测试条件（步骤 4-5）；仅约 5% 与 ATE 系统本身有关（步骤 6-7）。**优先聚焦硬件和接触**。

## 调试起步：确认关键条件

- **测试条件对齐 DFT**：ION、VGS、高边/低边/内部开关管、电流方向（体二极管影响）、测量点（封装引脚 vs 内部 Kelvin Sense）
- **Pin Map 与电流路径**：Force 输出/回流引脚、Sense 测量引脚、VGS 偏置、继电器路径、有无并联通路（ESD/体二极管）分流

## 未进入测试模式（第一类）三大原因

1. **功率管没真正打开**：控制信号未到位 / 上电顺序错 / 未进测试模式 / 保护误触发 → 实测引脚真实 VGS、确认上电顺序、确认 Test Mode、先用 10% 规格电流试探
2. **ATE 强制条件没真正输出**：进入 Clamp / 量程错 / 继电器未闭合 / 资源冲突 → 查 Clamp 状态、确认量程满足大电流输出+小电压分辨率、查继电器指令
3. **接触不良致电流路径开路**：Socket/Pogo/探针氧化脏污、Sense 线开路 → Continuity/Kelvin Test、Site Swap 测试、显微镜检查

## 六大偏差根源（第二类）

| # | 根源 | 关键现象 | 核心排查方法 |
|---|---|---|---|
| 1 | Kelvin 测量错误 | RON 整体偏大；两线/四线结果差异巨大 | 确认 Force/Sense 在 DUT 端分离；排除「伪开尔文」 |
| 2 | 实测电流不一致 | 计算用 ION 与设定值不符；RON 无规律偏移 | 用 V_meas 与 I_meas 计算 RON（不是 I_set） |
| 3 | VGS/控制电压不足 | RON 偏大，未完全进入增强导通区 | 实测 DUT 引脚真实 VGS；排查大电流下 Source Bounce |
| 4 | 芯片自热（温升） | 脉宽增加 RON 增大；复测值比首测高 | 短脉冲测试（50-500μs）；调整顺序加冷却；脉宽扫描 |
| 5 | 测试时序不合理 | RON 重复性差；Site 差异大；采样点不稳 | 示波器看 Gate/Drain/Source 波形；增加 Wait Time + Sampling |
| 6 | ATE 与仿真偏差 | 固定偏移或比例误差 | 分析误差类型；确认仿真是否含 Metal/RDL |

## 速查手册（典型问题快速判断）

| 现象 | 可能原因 | 优先检查项 |
|---|---|---|
| RON 极大 | 功率管未导通 | 测试模式、VGS/EN、上电顺序 |
| 测试电流为 0 | 电流路径开路 | 电流源、继电器、Socket 接触 |
| PMU 报 Clamp | 负载过大/电压余量不足 | DUT 是否导通、Clamp 电压设置 |
| RON 整体偏大 | 路径阻抗被计入 | Kelvin 连接、Socket/Pogo 接触电阻、PCB 走线 |
| RON 整体偏小 | 测量点错误/并联通路 | Sense 点位置、体二极管、并联导通路径 |
| 重复性差 | 接触不良/时序不稳 | Wait Time、继电器稳定时间、前置测试项 |
| 首测正常复测偏大 | 芯片/夹具温升 | 测试脉宽、间隔冷却时间 |
| 仅某 Site 异常 | 该 Site 硬件问题 | Site Swap、查该 Site 独有继电器/通道 |
| ATE 比仿真高 | 路径附加阻抗/温升更严重 | Kelvin 点位置、脉冲条件、接触电阻 |
| ATE 比仿真低 | 条件不一致/Sense 更靠内 | 严格对齐 ION/VGS/温度/脉宽 |
| 量产良率渐降 | Socket/探针老化 | Socket 使用次数、定期维护更换 |

## 短路校验法（定位问题域）

短接 PCB 上 Drain/Source 测试点，结果应接近 0Ω；用于定位问题在「测试机+PCB」还是「芯片端」。

## 10 条经验总结

1. **看全貌**：同时关注电流、电压、控制信号、Clamp 状态，不只盯 RON 值
2. **核心是 Kelvin**：Sense 点错误结果必不可信
3. **警惕温升**：脉宽越长 RON 越易因自热偏大
4. **对比需严谨**：ATE vs 仿真保证电流/电压/温度/脉宽/测量点完全一致
5. **定位问题域**：单个 Site 异常→优先查硬件路径；所有 Site 异常→优先查程序与公共条件
6. **先试探后加压**：大电流前先用小电流验证导通路径
7. **慎用补偿**：先确认偏差来源是稳定可解释的系统误差，再决定是否补偿
8. **保存原始 Log**：必须含 I_set / I_meas / V_meas 及波形
9. **问题多因性**：RON 异常常是接触/温升/时序/程序多因素共同导致，需系统排查
10. **黄金法则（四步法）**：画电流路径 → 量真实波形 → 看原始数据 → 做条件对齐
