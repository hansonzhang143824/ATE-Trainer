# 模块 02：BUCK / BOOST 拓扑（power stage 结构）

> 初稿（待用户校验）：用户提供 + 领域知识整理。用于理解电源芯片功率级结构，推导测试项的电压/节点关系。
> ⏳ **待用户修改校验**，固化为权威前请核对。

## 1. 功能

电源芯片核心是**功率级**，把输入电压转换成受控输出电压。两种基本拓扑：

- **BUCK（降压）**：Vout < Vin。HS 开关管(上管)+LS 开关管(下管)+电感+输出电容。
- **BOOST（升压）**：Vout > Vin。电感 + 开关管 + 二极管/同步整流 + 输出电容。

## 2. 硬件结构（关键节点）

| 节点 | BUCK | BOOST | 说明 |
|---|---|---|---|
| **SW** | 开关节点（HS Source + LS Drain） | 开关节点（HS Source + LS Drain） | 功率级中点，散热/开关损耗最大 |
| **HS (上管)** | Vin→SW | SW→Vout | 高侧开关，需自举驱动（见模块 01） |
| **LS (下管)** | SW→GND | Vin→SW | 低侧开关，同步整流 |
| **BST** | HS 自举电容端 | HS 自举电容端 | 与 SW 间自举电容（见模块 01） |
| **PMID/输出** | 输出/负载端 | 输出/负载端 | 不同芯片命名（PMID、VOUT 等） |

## 3. ATE 测试方法（通用）

- **基本供电**：给 Vin（VBUS/VBAT）、使能（EN）、参考（VREF）施加额定电压
- **拓扑相关节点**：SW、BST、PMID/输出为关键测量/供电节点；用 Kelvin 四线精确测量
- **驱动检查**：需确认 HS/LS 导通/关断时序（涉及 BST−SW 自举、PWM 逻辑）
- **测开关管**：
  - HS RON：需 HS 导通（BST−SW ≥ 阈值）+ 大电流（见模块 01 派生知识）
  - LS RON：需 LS 导通 + 电流
- **效率/损耗**：测输入/输出功率 → 效率；开关损耗需示波器/时序（ATE 常用简化版）

## 4. 派生知识（可推导的测试要求）

| 想知道/要测 | 推导 |
|---|---|
| **SW 电压关系** | BUCK：HS 导通 SW≈Vin，LS 导通 SW≈0；BOOST：SW 是电感节点（Vin~Vout） |
| **HS 导通前提** | 必须 BST−SW ≥ 阈值（自举充足）→ 测 HS RON 先建立自举 |
| **LS 导通** | 直接由芯片驱动，无需自举（低侧直驱） |
| **哪个节点需供电/测量** | 按拓扑：BUCK 测下管看 SW/LS；测 HS 看 Vin/SW/BST |

## 5. 易错点

- ❌ 把 BUCK/BOOST 的 SW 当固定电压——SW 是**开关节点**，随 HS/LS 状态在 Vin 与 0 之间切换
- ❌ 测 HS RON 时忘建自举（BST−SW）→ 管子没导通 → 测错
- ❌ 混淆 PMID 与 SW 的角色（不同拓扑/芯片 PMID 含义不同，需按项目解析）
