# 模块 03：上/下管 MOSFET 驱动（HS/LS switch drive）

> 初稿（待用户校验）：领域知识整理。用于推导"测某个开关管需要什么导通条件"。
> ⏳ **待用户修改校验**。

## 1. 功能

电源芯片用 **HS（高侧）/ LS（低侧）两个功率开关管** 做 PWM 切换实现电压转换。驱动二者的条件不同，直接决定测试时如何让管子导通。

## 2. 硬件结构（驱动方式对比）

| 开关管 | 驱动方式 | 导通条件 | 备注 |
|---|---|---|---|
| **LS（低侧）** | 芯片直接驱动（源极≥参考地） | VGS_LS > 阈值（如 5V），源极接 GND/PGND | 简单，源对地固定 |
| **HS（高侧）** | **自举驱动**（浮动） | **BST−SW ≥ 阈值**（VGS_HS，如 5V） | 源极 SW 是浮动的（随开关切换），须自举电容 |

**关键**：
- LS 源极接地 → 驱动电压固定在 GND-VCC 之间，好理解
- HS 源极接 SW（浮动节点）→ 驱动电压必须"浮"在 SW 之上，靠 BST−SW 自举（见模块 01）
- 所以 **HS 的导通 = 必须建立 BST−SW 压差**；LS 的导通只需芯片给 VGS_LS

## 3. ATE 测试方法（通用）

- **确认开关管完全导通**：
  - 测 HS（如 HS RON）：先建立自举 BST−SW ≥ 阈值（模块 01），芯片驱动 HS 导通
  - 测 LS（如 LS RON）：芯片驱动 LS 导通（常开/强制 PWM 对应状态）
- **导通后**：在开关管两端（Drain-Source，如 PMID−SW / SW−PGND）注入电流，测压差 → RON
- **观测**：开关管导通状态可由 VGS、VDS（压差）、输出节点电压间接验证

## 4. 派生知识（可推导的测试要求）

| 想知道/要测 | 推导 |
|---|---|
| **测 HS RON** | 必须 HS 导通 → **必须先有 BST−SW ≥ 阈值**（自举），再注入电流 |
| **测 LS RON** | LS 直接驱动 → 芯片开 LS 即可，无需自举（SW 被拉到 PGND≈0V） |
| **为什么 BST−SW 是前提** | HS 源极浮动，VGS 靠自举提供（模块 01） |
| **SW 电压状态** | HS 导通→SW=PMID/输出侧；LS 导通→SW≈PGND |

## 5. 易错点

- ❌ 测 HS RON 直接注入电流但没建自举 → HS 未导通 → 测到的是体二极管/关断态
- ❌ 混淆 HS/LS 的驱动条件（HS 需自举，LS 不需）
- ✅ SW 是浮动节点，测 HS 时 SW 会跟随 PMID（导通后）

## 6. 实例引用

- RDSON 黄金案例（HS RON）：BST−SW 恒 5V + PMID 台阶 + FPVI 大电流 + Kelvin
- TM640（BOOST HS OCP）：HS 导通 + 大电流过流检测
