# RDS(on) 导通电阻（chip Block）

> 具体参数类型族 **RDSON**。四件套：`L1-chip/RDSON`(是什么) + `L3-method/RDSON`(怎么测) + `L4-Golden-code/RDSON`(长啥样) + `L5-debug/RDSON`(怎么排查)。
> 测试方法见 `L3-method/RDSON.md`；优秀案例 `L4-Golden-code/Rdson.cpp`（官方）与 `L4-Golden-code/tm600-normal-highcurrent.cpp`（大电流+浮动源黄金案例）。

## 是什么

导通电阻（记为 RON 或 RDS(on)）是功率器件最关键的**直流参数**之一，直接决定器件导通状态下的功耗，进而影响系统效率、温升和可靠性。

## 定义（欧姆定律）

```
RON = VON / ION
```

| 量 | 含义 |
|---|---|
| VON | 功率管导通后，漏极与源极之间的压降（等效导通压降） |
| ION | 测试时通过功率管的电流 |
| VGS | 使功率管进入导通状态的栅极电压 |

**功耗关系**：P = I² × RON —— RON 直接决定导通损耗、温升与可靠性。

## Kelvin 四线法（毫欧级必须）

对于毫欧级低阻测量，**必须采用 Kelvin 四线法**：

- **Force 线**：提供测试电流（大电流）
- **Sense 线**：高阻抗测量电压（几乎无电流）
- 两者在 **DUT Pin 端分离**，从而避免线阻、继电器阻抗、接触电阻引入测量误差

> 低阻测试的准确性基石 = 正确的 Kelvin 四线法连接；Sense 点错误，结果必不可信。

## 易受干扰因素

导通电阻测试看似简单，实则极易受多种因素干扰：

- 接触电阻
- 电流路径完整性（是否有体二极管/ESD 等并联通路分流）
- Kelvin 连接正确性（Sense 点位置）
- 测试时序（导通建立/稳定/采样时间，VGS 施加）
- 芯片自热（脉冲宽度越长，RON 越易因自热偏大）
- PMU 量程设置（是否进入 Clamp）
- 前序测试项残留状态

## 需对齐的测试条件（DFT）

- 测试电流 ION 具体值
- 栅极/控制端电压 VGS 具体值
- 被测对象：高边管 / 低边管 / 内部开关管
- 测试电流**方向**（需考虑体二极管影响）
- 测量点：封装引脚电压（F&S 在引脚处短接）还是芯片内部 Kelvin Sense 点电压（F&S 独立走线到内部）
