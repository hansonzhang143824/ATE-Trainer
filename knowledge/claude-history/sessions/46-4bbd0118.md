## 结论：你不需要 git 账号

DeepSeek Harness（`dsh`）官方推荐用 **npm/npx** 安装，一条命令搞定，全程不需要 git、不需要 GitHub 账号：

```bash
npx @deepseek-ai/dsh web
```

- 你的 Node v24.18.0 完全满足要求（要求 v18+ / 推荐 v22+）
- npx 会自动下载包并启动网页界面（默认 `http://127.0.0.1:3080`）
- 想装成固定版本：`npm install -g @deepseek-ai/dsh` 然后 `dsh web`

即使是"从源码安装"那条路（`git clone` 公开仓库），**克隆公开仓库也是匿名可读的，同样不需要账号**。账号只在你想**提交代码 / 参与开发 / 拉取私有仓库**时才需要。

## 万一以后还是想要 GitHub 账号（自己动手 5 分钟）

1. 打开浏览器访问 👉 **github.com**，点右上角 **Sign up**
2. 依次填：邮箱（用你能收件的，如 163/QQ/公司邮箱）→ 设置密码（≥8位）→ 用户名（登录名）
3. 做个简单的**验证谜题**（选图/拼图，证明不是机器人）
4. 邮箱会收到一封验证邮件，点里面的 **Verify email address** 就激活了
5. 注册完可以用网页版（无需装任何软件），或之后再用 `git` 命令配置：
   ```bash
   git config --global user.name "你的用户名"
   git config --global user.email "你的注册邮箱"
   ```
6. （选做）以后要从账号拉私有仓库，可以装 [GitHub Desktop](https://desktop.github.com) 图形化工具，登录即可，不用记命令行。
