**FPVIe 是 STS8300 测试机里的"大电流四象限功率 VI 源表"板卡**（High-Current Four-Quadrant Power VI Source Meter）。

## 核心定位

一句话：**一台能"输出 + 测量"大电流电压/电流的高性能源表板卡**，是 STS8300 的源表家族里专管大电流的那块。你项目里凡是 ≥200mA 的大电流测试，按规则就应该用 FPVIe（见 `nuvolta-high-current.md`：14 项检查清单）。

## 关键参数

| 项目 | 规格 |
|---|---|
| **最大输出电压** | ±100 V |
| **最大输出电流** | ±10 A |
| **通道数** | 每块板 2 个通道（板内索引 0–1） |
| **工作模式** | 四象限（可源可沉，正负电压/电流都能出能吸） |
| **恒压/恒流** | `FV`（恒压）/ `FI`（恒流）两模式 |

## 板卡编号方式

槽位绑定字符串形如 `"S4_0,S4_1"`：`S4` = 插在第 4 号槽，`0,1` = 板内通道。多工位（multi-site）时用 `STSSetMultiSiteBind(MD_FPVIe, SITE_n, ...)` 把各工位物理通道绑到逻辑通道上。

## 它能干什么（能力清单）

1. **源 + 测一体**：`Set()` 设输出，`MeasureVI()` + `GetMeasResult()` 回读电压/电流（每次调用电压电流同时测，用 `MVRET`/`MIRET` 选读哪个）。
2. **脉冲输出**：`Pulse()` 出可调幅度/宽度的脉冲。
3. **任意波形 AWG**：`AwgLoader()` 灌波形（ramp/正弦/自定义），`AwgSelect()+STSAWGRun()` 多源同步，或 `AwgRun()` 单板独立跑。
4. **触发测量**：`SetMeasVTrig()`/`SetMeasITrig()` 设电压/电流边沿触发，抓 AWG 扫描中的翻转点（你项目里 Toggle 测试常用）。
5. **接触检测**：`ContactCheck()` 判高/低边接线接触，接触电阻 < 100Ω 判 PASS。
6. **钳位保护**：`SetClamp()` 设正负限流百分比（模式切换会重置回 102%）。

## 量程（写测试代码时常用）

- **电压档**：100V / 40V / 20V / 10V / 5V / 2V / 1V / 100mV（`100MV` 只能测不能出）
- **电流档**：10A / 2A / 1A / 100mA / 10mA / 1mA / 100µA / 10µA

| ACM200 | 精密源表（核心、高精度小信号） |
| HVIe | 高压（≤3000V） |
| HPVIe | 大功率 |
| QVMe | 快速 VI + FFT |
