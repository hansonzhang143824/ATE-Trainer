## 背景：CBIT 四阶段分工

| 阶段 | 做什么 | 由谁 |
|---|---|---|
| **P1 单点** | 生成 relay.h 单点继电器 `#define` | 本脚本生成 |
| **P2 通路** | 生成通路（多继电器组合） | `gen_paths.py --json` |
| **P3 通路命名** | 通路宏命名发布（275 条已在 StdAfx.h） | `gen_path_defines.py` |
| **P4 校验** | V1~V8 八项校验 | 本脚本校验 |

> **"单点"** = 只闭合**一个**继电器就能完成连接的继电器（每个对应一个 CBIT 位号），relay.h 里只有这些。通路（如 BUS/Share 需组合多个继电器）不在这里。

## P1 单点生成：动态读 CBIT 表 Excel（不是硬编码）

```text
CBIT表-DALI.xlsx
  col0 原位号 (K25_VCC_F / K25_VCC_S ...)     ← 按行
  col10 CBIT通道 (S34_CBIT2 / S36_CBIT5 ...)
```

1. 读每行继电器的 CBIT 通道 → 转位号：`S34_CBITn` → `n`（0~127），`S36_CBITn` → `n+128`（128~255）
2. **共享同一 CBIT 值的多个名字 → 合并成一个单点名**（`merge_names`，优先级）：
   - KELVIN F/S → `_FS`
   - 普通 F/S 单字母 → 去后缀：`K25_VCC_F`+`K25_VCC_S` → **`K25_VCC`**
   - `_Force`/`_Sense` 全词 → `_FOS_SNS`
   - BUS 方向合并（FH+SH / FL+SL）
3. 输出 relay.h 的 `Single-Point Defines` 块：
   ```c
   #define K25_VCC 25          // 同一 CBIT 的 F/S 合并
   #define K45_SW_BST 45
   ```

## P4 校验：V1~V8 八项检查

| 校验 | 内容 | 数据源 |
|---|---|---|
| V1 | 位号不重复（同名不同值 → FAIL，同值别名可） | Excel |
| V2 | **通路完整性**：SCH-Connect-Map 里"需闭合"的继电器位号都必须在定义里 | `--map` |
| V3 | 命名规范：K 开头、无 `_Sx` 工位后缀 | 生成结果 |
| V4 | 位号范围 0~255，且来源正确（S34 区间 / S36 区间） | Excel |
| V5 | 单点不遗漏：Excel 所有位号都有 define | Excel |
| V6 | Force/Sense 成对必须合并 | Excel |
| V7 | FPVI/QVM 通路命名（B 路径防御性） | `--map` |
| V8 | **交叉一致性**：每个继电器原始名必须在 COMPONENT-STATISTIC 功能分类清单里（数据源无漂移） | `--stat` |

## 三个 flag 分别对应什么

```bash
python gen_cbit_defines.py --cbit <CBIT表.xlsx> --stat <COMPONENT-STATISTIC.txt> --verify <relay.h>
```

- **`--cbit`**：CBIT 表 Excel（P1 的数据源，必填，默认从 project_config.json 取）
- **`--stat`**：COMPONENT-STATISTIC.txt → 喂给 V8（CBIT 表 vs 功能分类交叉核对）
- **`--verify`**：**对拍**——把目标文件（relay.h 或 AI.cpp）里现存的每个 `#define Kxx N` 提取出来，跟脚本这次生成的输出逐条核对：值必须在生成结果里；**目标有脚本无的值 → ERROR**；同名不同值 / 名字跟规范不一致（同值）→ WARN

所以这条命令 = **P1 从 Excel 权威源重新生成单点定义 → P4 跑 V1~V8 → --verify 跟现有 relay.h 对拍**，确认"脚本生成的结果"与"工程里已存在的宏"完全一致（没有脚本该有却没有的、没有该合并没合并的）。

另外注意：V2/V8 分别要 `--map`（SCH-Connect-Map）和 `--stat`（COMPONENT-STATISTIC），这两个 DALI 都已生成好（2026-08-26 重新解析过），所以现在跑是**完整校验**不是 SKIP。DALI 有 SCH-Connect-Map，走 B 路径完整四阶段。
