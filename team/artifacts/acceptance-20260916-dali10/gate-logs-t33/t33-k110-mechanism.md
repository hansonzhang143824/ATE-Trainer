## 3. 权威结论（三句，逐条由上表支撑）

1. **K110 是 ACM 路线的**单点换向**开关**：其公共端即 ACM 源差分对
   （COM1=3 → `S5_ACM200_SH18`、COM2=6 → `S5_ACM200_FH18`）；
   **通电**（3-4 / 6-5）→ 到达 `BST_S_S1` / `K57` 侧（**BST**）；**默认未通电**（6-7 / 2-3）→ 落到
   `PB0_F/PWM1_F` 侧。⇒ **不 SetOn 时 ACM 源到不了 BST**（与 `SCH-Connect-Map.txt:43` 的
   `… K109(ON) → K110(ON) → BST_F` 以及 `:724` `S5_ACM200_FH18 -> K110(Relay-NC) -> PB0_F` 完全一致）。
   ⇒ **K110 必须 SetOn —— 实现缺闭合是真缺陷。**
2. **K109 不属 ACM 脚路线**：其公共端（2/3 与 6/3 组）落在 `FPVIe1_FL_BUS_S1` / `FPVIe1_SL_BUS_S1`，
   与 K110 公共端**仅是"同 net 相连"（`NetK109_BUSL_PB0_S1_4/_5` 同时列出 K109.4/5 与 K110.6/3）**，
   **同 net ≠ 串联** ⇒ 属另一条路线/耦合。
3. **但契约字面权威仍要求 K109**：`tmDeltas.TM600.relaySet` 含 109，
   且 `pinRouteTable.BST["…CH0 Low"].needsClosed = [109,110,138,139,145,146]`（rev 24）
   ⇒ **t29 闭 K109+K110 = 依约保守、合规**（不是错误，也不应被后人当作"多闭"删掉）。
