## 2. 我自己的假阳性更正（novelty check）

我最初用一个 token 启发式扫描部署态，得到「无任何函数的 `SetOn` 同时含 `{K154|K155, K60, K61, K48, K76}`」以及「无任何函数含 `{K48,K76,K60,K61,K83}`」，于是怀疑 TM600/TM601 的修法会造出**前所未有的电路组合**（ACM200 与 FPVIe0 同时接 SW）。

**该怀疑是假阳性，现撤回。** 根因：我的启发式只匹配**裸 token**，而部署态**大量使用复合宏**（`K_FPVIH_TO_PMID_A`、`K60_BUSL0_VCP` 等），因此 `TM640:7513` 那类**宏写法**的闭集没被识别。改用**宏展开**核对后：`TM640:7513` 闭的正是 `K_FPVIH_TO_PMID_A(=83) + K60 + K61 + K13 + K57 + K48 + K76 + K65`，**与「TM600 补两条腿」后的形状同类**。

## 3. 电路事实：不是「双驱动」，而是「一个接口节点 + 两条互斥支路」

`SCH-Connect-Map.txt` 逐行（FACT）：
```
673-674: F: S5_ACM200_FH5 -> K48(ON) -> K76(ON) -> BST_F / S: ... -> BST_S      ← ch5 经 K48+K76 到 BST
178-179: S1_FPVIe_FH0  -> K46(ON) -> K48(NC) -> K49(NC) -> SW1_F / S1_FPVIe_SH0 -> ... SW1_S   ← K48 默认投 → K49 → SW1
175-176: S1_FPVIe_FL0  -> K89(NC) -> K60(ON) -> K61(ON) -> SW_F / ... -> SW_S   ← FPVIe0 低端到 SW
771-773: SW 需闭合 K61；F: S5_ACM200_FH8 -> K61(ON) -> SW_F / S: ... -> SW_S     ← ch8 经 K61 到 SW
775-776: F: S5_ACM200_FH5 -> K48(NC) -> K49(NC) -> SW1_F                          ← 同一个 ch5 还能经默认投到 SW1
```
**结论（INFERENCE，证据强）**：`K48` 与 `K61` 处在**同一条物理线**上，且
- **K48 = 该接口节点**（`K48` 通电 → `K76` 侧；
- 两个目的地**互斥**：`K48` 通电 ⇒ 默认投（`K49`→SW1）断开；`K48` 释放 ⇒ 改投 SW1。
因此 `S5_ACM200_FH5` 与 `S1_FPVIe_FL0` **不是两个同时驱动的源**，而是**经不同支路接向不同节点**（BST 与 SW）。⇒ **我原先担心的「ACM200 与 FPVIe0 同时驱动 SW」不成立**；修法在拓扑上是**已知形状的复用**，不是新电路。

## 4. 但仍存在的真实限制（必须写进报告）

1. **门禁只比文本集合**：它不校验 `K48/K76` 的**实际贯通**、也不校验 V 值/阶梯（见 `sandbox-fix-verification.md` §4）。
2. **`K48` 有两个开关状态语义**：`K48(NC)` 与 `K48(ON)` 通往**不同目的地**（SW1 vs BST）。因此实现时必须保证**同一次 `SetOn`** 内 K48 的状态是本 TM 的目的地——这与 t47「一条物理线三态一次一目的地」一致，也解释了为何不能另起第二次 `SetOn`。
3. **`K46` 的差异**：TM640 的闭集含 `K46`（`K_FPVIH_TO_PMID_A = 46,48,76` 中的 46），而 TM600 的既有闭集**不含 K46**。`K46` 是 FPVIe[H]→BST 与 FPVIe CH0-High 路径上的 P2P MOS（`relays.md:99`）。⇒ **TM600 修法若只补 K48/K76 而不补 K46，是否仍满足其操作点，必须由 `t2` 判定**（本文件不裁定）。
4. **TM601 的 BST 供给是否必需**（LS 导通不依赖 BST）仍是 `t2/t7` 的问题；本文件只证明「若要供给，K48/K76 是既有可用路径」。
